# 制作計画（Phase 2〜3）

各段の作業はすべて Python スクリプト化し（`blender -b -P`）、何度でも再生成できるようにします。
各段の最後に、写真と同じ画角の比較画像（低解像度プレビュー）を作り、合否を判断します。

| 段 | 内容 | 成果物 | 合格条件 |
|---|---|---|---|
| P2-0 | 写真4枚のカメラ解析 → フィン間隔・階高・スクリーン範囲を確定 | `data/cameras.json`、重ね合わせ図 | 角と外形線の残差 15 px 以下（1280 px 基準） |
| P2-1 | 外形・スラブ・コア・内側ガラス（曲面パネル） | `qfront.blend` 第1版、クレイレンダー | シルエットの重ね合わせが一致 |
| P2-2 | 外側フィン・横桟・ブラケット（GeometryNodes） | 拡大プレビュー（Q016 と同じ画角） | フィン本数と陰影のリズムが写真と一致 |
| P2-3 | 王冠トラス・屋上デッキ・QFRONT 文字 | 夕景プレビュー（Q031 と同じ画角） | トラスの透け方と文字位置 |
| P2-4 | 1F〜3F（店構え・庇・X形ブレース・サイン） | 正面プレビュー（Q107 と同じ画角） | 店構えと看板帯の高さ |
| P2-5 | 室内（2〜8F）：天井照明・什器・奥行き | ガラス越しの昼夜プレビュー | 室内の層が「奥に見える」こと |
| P2-6 | Q's EYE：SMD 面＋アートビジョン LED | 夜のプレビュー | 発光の滲み・画素感・フィン越しの見え方 |
| P2-7 | PBR 仕上げ：汚れ、雨だれ、ガラス面の歪み | 昼の拡大プレビュー | 新品のCG臭さが消えること |
| P2-8 | 周辺コンテクスト（地面・横断歩道・周囲ビルを簡易な箱で） | 昼夜プレビュー | 映り込みと環境光が自然 |
| P3 | 昼夜の最終レンダー（2560 px 以上、高サンプル）と評価 | 比較画像と評価表 | 6項目評価（下）、未達成点の明記 |

## 評価表（Phase 3）
各項目を、同じ画角の実写と並べて 0〜3 で採点し、根拠となる画像の該当部分を示します。
1. 形状の一致：重ね合わせの残差
2. 外壁と窓の材質
3. ディスプレイの発光
4. ガラスの反射
5. 室内の奥行き
6. 写真としての自然さ

AI の主観だけでは合格にしません。採点表と画像を提示し、最終判断はオーナーにお願いします。

## レンダリング予算（CPU）
- **プレビュー**：960 px、64 サンプル＋OpenImageDenoise で、1枚 5〜15 分を見込みます。
- **最終**：2560〜3840 px、512〜1024 サンプルで、1枚 1〜4 時間を見込みます（シーン規模による）。夜景はライトツリーを使います。

## 運用
- 独立リポジトリ（現在はローカルの git）に、スクリプト・ドキュメント・小さいデータを置きます。
- `.blend` と大きいレンダーは成果物フォルダに置き、必要に応じて Git LFS で管理します。
- GitHub の新規リポジトリは、オーナーの許可が出たら作成します。
