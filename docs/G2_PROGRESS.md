# G2 途中経過：QFRONT の WebGL 版の品質と計測の準備

## 今回入れたもの
- **品質の切り替え**：URL に `?q=low|medium|high` を付けて選びます（指定しなければ medium）。
  - 切り替わる項目：画面の解像度倍率の上限、アンチエイリアス、影、影の解像度。
  - low は影なし・倍率 1 です。内蔵 GPU の PC で最初に試す設定として用意しました。
- **30 秒計測ボタン**：押すと 30 秒間計測し、結果を JSON で表示します（ブラウザのコンソールにも出力）。
  - 記録する項目：FPS、フレーム時間（中央値と 95 パーセンタイル）、描画呼び出し数、三角形の数、解像度、GPU 名、ブラウザ、品質、昼夜、視点。
- **夜の投光器**：側面だけを照らす向きと強さに直しました。地面に大きな光だまりができなくなり、Q031 の写真の見え方に近づきました（`evidence/g2/`）。

## 未解決
- **ブルーム（光のにじみ）**：この環境（ヘッドレスのソフトウェア描画）では画面全体が白くかすむため、**既定では切っています**。
  - `?bloom=on` で有効になります。実際の GPU で正常かどうか、確認をお願いします。
  - 強さは `bs=`、しきい値は `bt=` で調整できます。
- **昼の前面ガラス**：写真より少し明るいです（平均 RGB で写真 87〜98 に対し WebGL 99〜108）。原因は、フィンと横桟が日光を受けて明るく見えていることです。ガラスの反射ではありません。

## オーナーの PC での計測手順（お願い）
```
npm ci
npm run dev
```
次の 3 つの URL を開き、それぞれで「30秒計測」を押して、結果の JSON を貼り付けてください。
- `http://127.0.0.1:5180/?q=low`
- `http://127.0.0.1:5180/?q=medium`
- `http://127.0.0.1:5180/?q=medium&time=night`
