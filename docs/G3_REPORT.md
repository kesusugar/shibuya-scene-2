## 3. カメラ合わせ（M027）
| 項目 | 値 |
|---|---|
| 方法 | 点 3 つ（塔の角の上端、隅切りの足元、塔の南東の上端）、縦の線 3 本、帯窓の向き 1 本、遠くの人の目の高さ（地平線）を、最小二乗法で合わせた |

| 注意 | 写真の画素を読み取る精度は ±5〜10 px 程度。南面はほぼ真横から見えているので、その方向の奥行きの誤差が大きい |

## 5. ブラウザ（WebGL）
- `?buildings=qfront,magnet,eiraku` で 3 棟を同時に表示できます。`M027視点` ボタンで、写真と同じ視点になります。
- **建物ごとの分離**：存在しない建物を追加して確認しました（`evidence/g3/isolation_missing.png`）。その建物だけが赤い仮の箱になり、他の 3 棟は表示を続けました。看板レイヤーの読み込みに失敗しても、建物本体は表示されます（自動テストあり）。
- **GLB の大きさ**：`magnet.glb` 9.8k 三角形、`magnet_signs_2025.glb` 16k、`eiraku.glb` 0.4k（文字の多くは看板レイヤーにある）。
- FPS は、ヘッドレス環境（SwiftShader）の値なので参考になりません。オーナーの PC での計測をお願いします。

## 6. 年代レイヤー
- 看板・広告・画面は `source/data/signage_2025.json` にまとめ、コレクション `08_SIGNS_2025` に組み立て、`magnet_signs_2025.glb` として書き出しています。

- 文字はフォントで作り直しました。広告と画面の絵は自作の仮の絵です。写真の画素は使っていません。
