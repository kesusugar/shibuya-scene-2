# スクランブルスクエア：北面の限定的な外装改善

## 結果
元のPLATEAU全壁・全屋根・地面36点を保ち、surface 77だけの共通外装を置換。上層は67本の不均等な複数階スリットと細い横桟へ変更し、低層西端は15列の浅い銀色フィンと下へ広がる輪郭を追加した。広告面は無地の筐体のみ。西側面91を含む他の面、Fukuras、QFRONT、西武、共有生成器は未変更。

## 基準モデルの確定
大きいGLBの取得を繰り返さず、元の生成器とPLATEAU/layout、記録済みの36個の地面サンプルを使い、Blender 4.2.3で再生成した。地面問い合わせを同一XYの記録値へ置き換えただけで、生成GLBは原manifestのSHA256 c184cadf05ebfbad08504664745377c3049b25e667019f03093a2459eb71f78d、2,350,656 bytesと完全一致。独立レビュアーも再生成一致を確認した。これは元の単体モデルのバイト一致であり、現行全景の取得・撮影を意味しない。

source/data/pavement-baseline.jsonは元statsの正規バイト、original-manifest.jsonは取得記録。source/blender/reproduce_baseline.pyは元生成器の地面再生版。XYが不明または重複なら停止する。元ソース・layoutの改行は原manifestと一致するよう正規化し、無意味な差分を出さない。

## 写真と形
2025-09-30昼、2025-10-10夜、2025-06-15の実画像を見た。西端A=(117.767,-104.738)から東端Bへuを増やし、扇状部を反転させない。下端z=4の幅30.2m、上端z=68の幅6.2m、フィン幅0.095m・最大壁前0.55m、上部スリット幅0.42mは写真からの推定。上端T.P.243.637m、全屋根段差と元壁は不変。

比較はfront / west_side / photo_sep30_angle / podium_closeの前後同一カメラ。写真側のカメラは未校正。単体スタジオレンダーであり、通常の交差点・広場の昼夜全景やWebGL表示成功の証拠ではない。写真の撮影日・作者・ライセンスと切出し範囲はsource/refs/FACADE_SOURCES.md参照。

## 残る差・不確実性
- 本物の深い低層後退・吹抜け・内部床・透明感は未再現。元壁を残すため浅い外装表現に限定した。曲線は平面内16折れ線の近似であり、実寸精密再建ではない。
- 67本へ増やし不均等な補助群を加えたが、実写真よりまだ疎で規則的な部分がある。忠実な採寸転記ではない。
- スリットの本数、各開始/終了、階高、色、実際の各フィン奥行は未測量。写真の反射や家具を床スラブに変換していない。
- 西側面91は旧近似のまま。北面との小さな見付差は残るが、新しいフィンは角の外へ回り込まない。
- 2025年10月の広告内容は未制作。無地の大きな筐体は情報量を持たない。常設名称・ロゴも未制作。
- 高層屋根の見た目に写真との差が残ってもPLATEAU形状を合わせて改変しない。
- 全シーン、FPS、CI、所有者PCは未検証。5項目の厳密な資産テストは全体の合格ではない。

## 再生成
Blender 4.2.3:

    blender -b --python-exit-code 1 -t 4 -P assets/buildings/scramble-square/source/blender/build.py -- assets/buildings/scramble-square/source/data/plateau.json assets/buildings/scramble-square/source/data/layout.json recorded assets/buildings/scramble-square/web

第3引数は従来CLIとの互換用で、地面は保存済み36点から再生する。新規地形を推測しない。出力GLBと編集可能blend、statsを更新する。元モデル再生は作業コピーのdataディレクトリと別出力先でreproduce_baseline.pyを実行する（候補statsを上書きしない）。共有生成器への依存はない。

## 実行済み検査
- 元の基準GLB：独立再生成を含めSHA256一致。
- 候補：44,392三角形、10 primitives、2,930,780 bytes。B上限120,000 / 40 / 3,000,000を維持。追加広告レイヤーなし。
- 資産テスト5件成功：全壁・屋根の三角形ハッシュ、北面以外の三角形ハッシュ、36接地点、全非WallSurface頂点、スリット法線、段差屋根を越えない新規頂点、予算。
- 使用可能な最新ソーススナップショットでtsc --noEmit / vite build成功。資産同期を伴うフルnpm test/buildや全景ロードは未検証。
- 独立レビューで発見した西側屋根段差上のスリット越境を修正し、再発防止の全頂点境界テストを追加した。

## 無地表示面の追検討
SEP30/JUN15の見える範囲では広告面の縦比率は低層フィン区画の約34〜44%。候補z4〜28 / フィンz4〜68 = 37.5%はその範囲にあり、画面が黒く目立つという理由だけで高さを縮めない。写真は未校正のためこの比率は実測寸法ではない。両写真で表示面にも見える縦横の区画線を、周囲のグリッドに揃えた浅い細線として追加し、扇形端から離して切り詰めた。部材がガラス方立かLED区画かは断定しない。表示面は非発光の控えめな灰青色へ変更したが、これは未点灯のプレースホルダーという表現選択であり、実物の反射色を測った値ではない。広告画像・文字・照明は追加していない。
