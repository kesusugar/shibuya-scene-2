# 見た目の土台（空・かすみ・質感・陰）と、小物の取り込み口

- 2026-10-14、ブランチ `claude/core-look-foundation`（PR #37 のブランチの上に積んだ）。
- 目的：単色の面の作り物感を、**全部の建物と路面に一度に**減らすこと。写真品質の完成ではない。
- 比較画像：`evidence/look-foundation/boards/`（前は `?sky=flat&detail=off&ao=off`、後は既定。前後は同じカメラ）。

## 1. 入れたもの
| 項目 | 内容 | 切り替え |
|---|---|---|
| 空 | 地平線の淡い青から天頂の濃い青へのグラデーション（以前は一様な青）。夜は濃紺から、地平線がわずかに明るい | `?sky=flat` で以前の空 |
| 遠景のかすみ | 300 m から 2.2 km にかけて、地平線の色に溶ける。遠くの建物が切り抜きに見えなくなる | 同上 |
| 路面の質感 | アスファルトに大小のムラと、ところどころ暗い補修跡。細かい粒で光沢も少し変わる | `?detail=off` |
| 歩道の質感 | ムラと 0.30 m 角の目地 | 同上 |
| 外壁の汚れ | 縦の汚れ筋と大きなムラ、足元 0.8 m の帯を少し暗く。**QFRONT・MAGNET・栄楽ビルには掛けない**（手作りの材質を保つ） | 同上 |
| 隅の陰（環境光の遮蔽） | 壁の足元・入隅・設備の下に陰（GTAO）。品質 medium と high で有効 | `?ao=off`、強さは `?aoi=` |

- 質感は UV を使わず、画面上の世界座標で自作の模様（乱数の種で固定）を読む。PLATEAU 由来の形には UV がないため。
- 模様の平均は 1 に近く、C3a で写真に合わせた区分ごとの明るさは平均では変わらない（テストで確認）。
- すでに自分のテクスチャを持つ面（広場の敷石、看板など）には掛けない。

## 2. 小物の取り込み口（ChatGPT の dots などで作ったモデル用）
- `tools/props/import_prop.py`：受け取ったモデルの足元を原点にし、実寸に縦横同じ倍率で合わせる。比率がずれていれば警告。三角形を減らし、遠景用の簡易版も作る。材質名を場面の区分に合わせる。
- `src/world/props.ts`：`assets/street/props/web/layout.json` の配置を、同じ種類ごとにまとめて描く。高さは地面から取り、地面がない所には置かない。
- 手順と依頼文の書き方は `assets/street/props/README.md`。
- わざと崩した試験用モデル（センチ単位・原点から離れた位置・部品 3 つ・重い球）で確認した：倍率 0.01 に直り、高さ 1.83 m・幅 1.00 m・三角形 15,516 → 2,000、遠景用 500。結果は `evidence/look-foundation/prop_selftest.json`。
- **配置した小物は、まだ 0 件。**

## 4. 正直な評価
- いちばん効いたのは**空とかすみ**。遠景に奥行きが出た。路面と歩道の質感は近くで効く。
- 外壁の汚れ筋と隅の陰は、画面なしの簡易描画（SwiftShader）では弱く見える。実際の PC の画面での確認が必要。
- 写真と並べると、まだ別物。看板・店先・人と車がないことの差の方が大きい。
- 性能：陰（GTAO）は画面全体に処理が 1 段増える。オーナーの PC で `?bench=auto` を使い、`?ao=off` との差を確認してほしい。
