# ハチ公像周辺の石縁・銀色レール・植栽
PR #28マージ後、像の周辺に写真で確認できる石縁と傾斜した銀色レール2区間、低木6株、自然石6個、石製掲示板1基を通常表示へ追加。レールを一般的な板座面ベンチへ置換しない。用途・正式な呼称は未確認。

## 根拠と制作
2025-07-13、RuinDig/Yuki Uchidaの094/095（CC BY 4.0）。元の写真はstreet/hachiko/source/refsにあり、SOURCES.jsonとmanifestで参照・ハッシュを残す。像を中心にした相対配置で、位置・寸法・向き・植物の種・10月の状態は未独立照合。7月の選挙告知板は再現しない。写真のカメラは校正していない。

石材の区切りと目地、上端、銀色の2本の管、傾斜した支持と脚、下部照明の筐体、枝と針状葉、自然石、石製掲示板の枠と暗い銘板面をBlender 4.2.3 CLIで自作。写真テクスチャなし。掲示内容・地図・点灯状態は不明なので文字・地図・発光を創作しない。植栽は球状の樹冠や既存OSM樹木の複製ではない。材質ごとにまとめて8描画単位へ。

## 写真比較からの補正
- v1: 石板が写真と左右逆、低木が疎らで低い。
- v2-panel: 石板の局所Xだけ+3.65→-3.65 mへ。像の向き自体は推定のまま。
- v3-density: 枝の扇形群を11→28へ。追加の枝葉だけ別乱数列を使い、元の枝・自然石・石縁を維持。
- v4-height: 低木の高さだけ0.67→1.10 mへ。カメラ・他の寸法・材質は保持。
- after: 細い葉が通常画面で消えて枝ばかりに見えたため、葉束の半幅だけ0.004→0.012 mへ。遠目の簡略表現で、実物の葉1枚の幅ではない。枝の配置・高さ・位置・色は保持。

粗い高さの目安はshape-check.json。7月写真で手読みした低木上端から後部レールまでの間隔は像の見える高さの約0.81倍。模型の設計比率は初版約0.35、補正後約0.77（実GLBの世界座標からの比率約0.75）。写真の画面比率と模型の世界比率は異なる量で、未校正カメラの透視・遮蔽・手読み・勾配の差を含む。位置精度・寸法精度・合格率として扱わない。植栽の密度・樹形・色、石材の風化と全体の区画はまだ実物と差がある。
