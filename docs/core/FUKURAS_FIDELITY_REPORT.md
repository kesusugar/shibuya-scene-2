- 18等分の太い階帯と斜めチェッカーを、細かい連続カーテンウォールと複数ベイにまとまる銀色パネルへ変更。銀色のまとまりにも各パネルの縦目地を残した。
- 下部は事務所窓の繰り返しをやめ、背の高い暗色ガラス、局所的な大きいキャップ、東面の3本の幅広い銀色リターンへ。
- 写真で見える斜め動線は、奥の殻を消さず、浅い立体側面を持つストリンガー、対になる手すり、汎用の縦支持材と小さな端部で表現。2本の線だけだった初案から修正。実際の階段数・内部寸法の再現ではない。

対象は元の壁76/81/135だけ。135は北東の短い接合面で、元の殻の形を変更していない。OCT11は鉄道側から西向きで、角の写真左が東面81。下部北側の104は別の張り出し面であり、写真左の銀色リターンと取り違えて変更しない。

## 寸法の根拠と推定

PLATEAUのsource z42.3の下部切欠きとz83.9の主面上端を区画の基準にした。これは階数・階高を断定するものではない。T.P.120.899を18等分しない。

- 上部主フィールドはsource z42.3–83.9。幅約1.8m、縦約2.85–3.0mの細かいパネル。OCT11の画素で縦細線が約10–16px、水平の区分が約16–25px程度に見えることと、SEP30の密なパネル群を参考にした概算。遠近・傾き・反射の影響があるため測量値ではない。
- 目地約90mm、下部の方立約90mm、疎な水平材約65mm。元の各面の多角形で切り詰め、屋根輪郭を横切らない。
- 銀色パネルは明示的な領域表。ランダム/剰余チェッカーではない。ただし写真の一枚一枚の位置を透視校正した復元ではなく、まとまり・明暗の種類を合わせた推定配置。
- 下部角の幅約18m。キャップsource z40–42.3の2.3m、東面リターン高さ3.1m。OCT11で下部の銀色帯が隣の暗い区間に対して大きいことを見て、初案1.1m/1.8mから太くした。写真では斜めに重なり正確な比率は確定できない。
- ガラス/枠/パネルは元の殻から65–250mmの表示奥行き。sourceの微小な非平面性により局所距離は約258mmまで。斜め動線の本体は奥行き60mmの浅い立体、手すり等はその手前・方立の奥。実物の階段の奥行きではない。

## 保持と再生成

元のGLBのbinary全体をそのまま先頭に保持。元の屋根219三角形と壁570三角形のプリミティブ・頂点・indexを変更せず、対象面の外装のindexだけを置き換えた。対象外の元の材質/頂点/法線/ノードを保持。地面135サンプルと足元形状は同じで、地面を新規に再照会したとは主張しない。欠測0、datumTP15、屋根移動0。

新GLBは12,231三角形、13プリミティブ、1,046,328byte。既存B予算120,000/40/3,000,000を変更していない。元GLB13,199三角形/8プリミティブ/781,556byteから、面数は減り、材質・保持元bufferによりファイルは増加。写真テクスチャ0。

Blender4.2.3で別の出力場所へ再生成したGLBのSHA256が一致：accdfc0288c42caa6ef956d63cc6be4196bee54be39b57dd5f4a95097dfb3a3d。packedblendも納品。手順はasset README。
