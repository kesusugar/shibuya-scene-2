## 配置・地面・推定

- [名称付きOSM輪郭](https://www.openstreetmap.org/way/1315939856) version5（2026-08-30）を位置・長辺方向の根拠にする。[運営者の施設紹介](https://shibuyaplusfun.com/news/detail/?cd=000224)はA8近接の観光案内施設であることを支持する。2026年OSMを2025年10月の実測とは扱わない。取得した必要数値だけを `evidence/box-1/box-position-source.json` に保存。
- 最初の輪郭中心合わせでは既存A8外装との約20cmの重なりが検出された。輪郭の広場側長辺を前面壁の推定基準へ変更した。中心案から約44cm広場側へ移動。OSMの奥行を建築壁間寸法と同一視せず、既存A8も引き伸ばさない。採用原点はplan `(25.108505, −46.695255)`、yaw `−81.083977°`、scale `[1,1,1]`。
- 公式図面由来の全幅12.559m等を保持。屋根・厚さ・床高・裏面・テラス深さ・部品の高さは推定。前テラス局所対応は既存比較資料の剛体平行移動だけを再利用。元テラスの正規化逆変換を二重に加えない。
- Core地面21点の高低差は約177mm。旧シェルの底を最低地面へ合わせると傾斜部が埋まったため、可視R3境界の上面が測った地面より5mm高くなる基準を採用。T.P.15m基準、原点のT.P.は15.489115m。**モデル下端Z=0や−0.164329を地面と読み替えていない。**
- 地面と元床底との見える隙間には、外周だけの推定スカート（最大約268mm）を追加した。これは地面へ閉じる技術的な表示部材で、現地の隠れた基礎形状の復元ではない。地下・内部・歩行面・collisionは追加していない。
- 全体を世界座標で一度だけ書き出す。viewerの `groundElevationTP=15` で追加の高さ変換をしない。正逆行列と全地面標本は `source/placement-and-build.json`。
