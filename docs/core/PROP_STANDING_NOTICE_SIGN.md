# 金属枠の自立式案内板（単体素材）

## 用途・配置候補
スクランブル交差点の歩道端・ハチ公側にある、低い自立式案内板を表現する素材。2025年10月10日の写真で存在と外形を確認したものです。候補位置は写真手前の横断歩道待機空間。座標・向き・継続設置は未確認であり、配置や既存画面の変更は行っていません。建物・道路・人・広告・照明・撮影用床はGLBに含まれません。

## 写真に合わせたところ
単一の丸い管の外周、縦長の薄い板、隅を丸めた暗い縁、6か所の小さな留め具、板の下の空き、横に広い浅い台座、2か所の接続部を制作。A型の二枚看板ではありません。塗膜剥がれは小さな不規則な面で近似し、画像テクスチャや非対応の手続き型シェーダーを使っていません。文字・紋章は複製せず意図的に無地にしています。

## 推定・未達
幅0.56 m、奥行0.29 m、高さ約1.10 mは制作上の推定で、実測ではありません。写真では高さが台座幅の約2倍、枠幅は台座幅の約9割、板高は全高の約7割です。夜の暖色光を受けているので昼の塗色は確定できません。台座の奥行、背面、板厚、留め具の細部も推定です。表面傷は写真の厳密な転写ではありません。比較用のカメラは近似で校正済みではなく、画質・配置の完成認定ではありません。

## ファイル・再生成
- incoming/standing_notice_sign/standing_notice_sign.glb が唯一の配布GLB。単一LOD、1つのメッシュ、メートル、足元中央原点。GLBはY-up、BlenderはZ-up、正面はBlenderの-Y。
- source/blender/standing_notice_sign.blend は部品を保持した圧縮編集用ファイル。STUDIOコレクションは撮影専用で書き出し対象外。
- source/python/generate_standing_sign.py をBlender 4.2.3で実行して再生成します。コマンド末尾の -- OUTPUT_DIR で出力先を指定できます。
- source/data/specs/standing_notice_sign.json はPR #38取り込み仕様です。
- evidence/standing_notice_sign/comparison.jpg は写真切り抜きとモデルの比較画像。前面・側面は別画像です。

再生成例:

    blender -b -t 4 --python-exit-code 1 -P assets/street/props/source/python/generate_standing_sign.py -- /tmp/sign-rebuild

## 後でシーンへ取り込む手順
PR #38の tools/props/import_prop.py がある作業ブランチで、同スクリプトに仕様、incoming GLB、生成先web GLB、report JSONを順に渡します。今回のmainには取り込みコードがないため、検証時だけ正確なコピーを外部で使用しました。取り込みコードやweb/への生成物はこの素材追加に含めません。配置は別作業で layout.json に位置の根拠を記載し、同じカメラ比較・全体予算・通常表示を確認してください。取り込みにlod_ratio=0を指定し、LODの重ね描画を避けています。

## 検証範囲
Blender 4.2.3での生成、編集用ファイルの再読込と可逆な頂点編集、元GLBとPR #38 importer経由GLBの再読込、寸法・足元原点・三角形数・有限値・材質・非対象オブジェクトの除外を確認します。確定した数値は添付JSONを参照。npm一式、WebGL統合、FPS、現場配置は未実施です。
