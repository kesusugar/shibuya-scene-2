# 西側街区の写真忠実度改訂 — レビュー候補

## 目的・使用箇所

交差点西側、センター街入口の既存 `west-block` の通常表示資産を改善する。対象 `way/136690966`。既存のQFRONT・西武は変更しない。新しい建物を別座標へ置く変更ではなく、既存のベースGLBと2025年1月看板レイヤーを同名で置き換える候補。マージは行わない。

## 写真と見た目

基準は2025-01-31、Syced / CC0の原寸写真。2025-02-07の同著者CC0写真を建築形状の別日照合に使用。広告は1月に限定し、2月や11月の内容を混ぜない。

- `evidence/west-photo-fidelity/comparison.jpg`: 写真 / 改訂前 / 改訂後。前後は同じ比較カメラ・照明。
- `evidence/west-photo-fidelity/after-full.jpg`: 改訂後の単体。
- `evidence/west-photo-fidelity/after-close.jpg`: 西村の開口・窓・タイル・庇の近景。

従来は薬局の黄色い看板が隣の細い案内表示に誤って切り出され、もんじゃには背後の鉄骨、DMMには黒い側面と欠けた広告が混入していた。原寸で四隅を読み直し、DMM・書店帯を実際の二面に分け、楽天の曲面は境界に沿って展開した。写真の広告文字を生成していない。

建築側は深い左開口、幅広のタイル壁、四段のカーテン窓、不均等な主枠、厚い緑の帯・薄い明色の端部、店先の奥行、庇の端部、看板枠・照明を制作。旧形状に細い枠を足すだけの変更ではない。

## 大きな比率の補正

- もんじゃ看板の旧中心25.4 m/高さ11 mを、中心22.55 m/高さ9.1 mへ推定改訂。写真より上へ伸びすぎていた関係を修正。
- 三千里薬品の青い縦表示と赤いクスリ面も写真の上下関係へ合わせた。
- 角の曲面画面は旧R4.8 mの強い曲率からR8 mへ変更。従来の推定ファサードが写真より細かったため、上部外装・看板の中心と外形も改訂した。
- 地面アンカー・source_id・元のPLATEAU入力・地理基準は維持。改訂した上部外形は測量済み境界ではない。外装の張り出し・隣接関係は実シーンで再確認が必要。

## 残る差を明示

1. 元PLATEAUの屋根奥・背面を残している。孤立描画では、写真で隣接建物に隠れる大きな部分が見える。
2. 店内、商品、入口の細かい配置は未確認部分が多い。写真に見えない裏側を正確に再現したとは言わない。
3. カーテンの細部は広告を含まない写真試料を他階にも再使用した推定。広告に残る焼き込み影と原画素数には限界がある。
4. 写真比較カメラは近似。看板四隅の残差が小さくても、地理座標・実寸・全形状が正しいことを意味しない。
5. 完全なフォトリアル再現・完成・全体シーン合格ではない。

## 再現性・技術確認

Blender 4.2.3 LTSで実際に生成・GLB出力・blend保存・レンダー。18画像をblendへパック。82点の既存測量キャッシュを用いた再生成経路を保存。独立した再生成で5つのweb出力がバイト一致。

現在: 7,602三角形、35プリミティブ、GLB合計1,056,140 bytes。既存予算120,000/40/3,000,000以内。敷居の下端が基準面より0.07 m下へ入るが、地面アンカーは不変。全体境界の東側増分は元資産比較で約0.132 m（他の看板の既存張り出しを含む全体bbox）。局所ファサードの変化を全体bboxだけで安全と認定しない。

未実施: 完全なリポジトリのnpm test/build、実シーンへの同期・全画面の比較、隣接建物との衝突確認、オーナーPCのFPS測定。限定スナップショットであるため、これらをPASSとしない。
