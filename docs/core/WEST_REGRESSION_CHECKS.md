# 西側街区の既存回帰テストとの契約差

対象: PR40 commit 15f8bc49dae0a6eec9a67c1bd329e7f669e2ddd6。変更は tests/west-block.test.ts のみ。資産・ジェネレータ・地面・QFRONT・西武は変更しない。

## 原因

1. west_sign_taiseido は、写真の角をまたぐ二平面を分離した west_sign_taiseido_left / west_sign_taiseido_right に置き換えられた。旧テストは存在しない単一材質を要求し、新二面の位置は検査していなかった。
2. 旧テストは看板が PLATEAU planBounds の東端 -34.818m 内にあることを要求した。しかし今回の facades.json は、半径8m・中心(-41.53,32.93)を写真に基づく「推定外装・看板の張り出し」として明示し、元のPLATEAU範囲を変更していない。初めの失敗0.155mは全体の最大張り出しではない。Rakutenの東端は-33.430141mで、PLATEAU東端から1.387859m。DMM/大盛堂右面は-33.448566mで1.369434m。
3. 旧遮蔽レイはDMMと大盛堂も円筒と仮定した。現在は平面パネルなのでレイの目標を各面の解析形状へ修正した。

## 修正と検証

- PLATEAU planBoundsは厳密に元値を固定。推定外装をPLATEAU範囲と呼び替えない。
- 写真比較済みの推定中心、半径、角度、幅、看板高さを固定し、設定とGLBを同時に動かすだけで許容範囲が拡大しないようにした。
- Rakuten全頂点の半径・角度・上下端・48三角形を確認。DMM/大盛堂左右は解析的な四隅と各2三角形を確認。数値誤差は2mm以下。
- 看板別の東端を0.5mm精度で固定。全資産の東端も-32.510506mに固定。旧資産の屋上看板がすでにPLATEAUから約2.176m張り出し、現資産全体は約2.3075m、増分約0.132m。
- 元Streamカメラから4面それぞれ3×3、計36点へレイを飛ばし、全西側基礎/看板メッシュを遮蔽物として先頭ヒットと目標位置を検査。全36点で目的看板が見える。
- 本物のcontext_input.jsonを使用した西側・駅前・第一勧銀のfocused test: 11/11 passed。全TypeScript typecheck passed。
- 負例3件を隔離コピーで実行: 大盛堂左材質消失、DMMを東へ0.1m変位、DMM前に不透明面を追加。いずれもテストが失敗することを確認。遮蔽負例は目的の「dmm hidden」断言で失敗。完了後GLBを元バイトへ復元しSHA256一致を確認。

## 限界

この変更は推定外装を測量済みと認定しない。写真に基づく形状変更の既存意図をテストへ反映し、将来の無意図な拡張・位置ずれ・旧シェル遮蔽を検出するもの。隣棟・歩道との衝突、全景の視覚統合、実寸の真値は未検証。全プロジェクトの全資産テスト合格という意味ではない。
