## 大木の配置・可視確認

- **同定の根拠**: 11月写真の幹は像の左後方の石縁内にあり、既存6本のOSM木は最も近いものでもこの場所から37m以上離れる。写真で異なる樹冠や柱を一本にまとめていない。
- **配置の推定**: 幹の底中心は計画 `(7.400,-45.500)`、像のOSM基準 `(11.568,-48.686)` から西4.168m・北3.186m。回転0°（モデルの南向き観察面を広場側へ）、均等倍率1。島状区画の境界から幹中心まで最短約1.84mで、推定基部径0.71mは境界を越えない。寸法8.88×7.03×8.82m、向き・位置は写真相対と地面形状からの**推定**。
- **接地の確定値**: 保存済み `ground_core.glb` に対する幹中心のレイキャストは T.P.15.43629m。入力地面の T.P.15.286mに島状区画の0.15m高が加わる。GLB底中心をWeb `(7.400,0.430,45.500)` に置き、中心で6mmほど埋める。周囲の地面試料はT.P.15.431～15.441m。標高計算を二重に適用せず、地形全体は変更しない。
- **異なる時期の組合せ**: 枝・幹は2025-11-01、緑葉は2026-08-08。両時期を同時の現況とは主張しない。写真テクスチャは使っていない。モデルの編集用原本とZIPはローカルに残し、GLBのみ採用。
- **見た目**: [全景の前](../../evidence/hachiko-held-20261017/before/rear_tree_whole.png) / [後](../../evidence/hachiko-held-20261017/after-grounded/rear_tree_whole.png)、[正面の前](../../evidence/hachiko-held-20261017/before/rear_tree_front.png) / [後](../../evidence/hachiko-held-20261017/after-grounded/rear_tree_front.png)、[斜めの前](../../evidence/hachiko-held-20261017/before/rear_tree_oblique.png) / [後](../../evidence/hachiko-held-20261017/after-grounded/rear_tree_oblique.png)、[足元の前](../../evidence/hachiko-held-20261017/before/rear_tree_feet.png) / [後](../../evidence/hachiko-held-20261017/after-grounded/rear_tree_feet.png)。同じ `pose`・視野角・昼表示で撮影し、`capture_log.json` にURL・状態を保存した。初回の足元で0.15mの浮きを発見し、生成済み地面GLBから修正して撮り直した。像、台座、石碑、BOX、JR入口、交番、既存6樹木に重複・干渉は見えない。石囲いが欠けたままの景観差は残る。

## 検証

`scripts/audit-station-louvres.py` は現行GLBを読み、共有材質内の各四角面を三角形の共有辺で識別する。建物や鋼材を変更しない。`scripts/probe-tree-ground.py` は表示用地面にレイキャストする。`scripts/hachiko-held-plan.py` は保存済みOSM/PLATEAU/地面の輪郭を図化する。A8と売場の既存構造物、ルーバーは数値・写真・案内図を照合したが施設対応に未確定要素が残る。

`tests/rear-tree.test.ts` は1本だけの読込、既存6本との分離、配置、分類、障害時の分離を検査する。`tests/budget.test.ts` は上限を変えずに新資産をA予算に含めて通過した。標準テストとbuildの結果はPR本文に記載する。マージ・デプロイはしていない。
