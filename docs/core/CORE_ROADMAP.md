# Core のロードマップ（Gate C0 の提案。オーナーの確認待ち）

- 全体の流れ：Tier 1（交差点の主役）→ 路面・駅側・街路設備 → 昼夜と写真品質の QA → Core v1 の凍結 → 周辺への拡張（パック 07）。
- **Gate ごとに PR を分ける**。
- 比べるときは、変更前と変更後を同じカメラ・同じ条件で撮る。
- 建物は 1 棟ずつ独立した GLB にする。どれか 1 棟が読み込めなくても、ほかの建物は消えない（2.0 のビューアーは、すでにこの方式）。

## 先に決めてほしいこと（C1 の前）
1. **西武 A 館の順位を下げる**かどうか。
   - 5 視点の見え方では 16 位で、3 視点からは見えない（`VISIBLE_GAPS.md`）。
   - 集めた参考写真と PLATEAU のデータはブランチに残し、C1 の Top 3 の後に再開することを提案する。
2. 優先度の点数の重み（0.45 / 0.25 / 0.20 / 0.10）をこのままでよいか。
3. 地面の基準面を T.P. 15.000 m にするか、14.916 m にするか（`TERRAIN_ALIGNMENT.md`）。
4. スカイラインの 5 棟の作り込みの程度。提案は、輪郭・高さ・ガラスの色まで（下の C1-3）。

## C2 — Core の道路・駅側・街路設備
- **地面**
  - PLATEAU の道路の標高から作る高さの網、車道と歩道の区別、縁石、スクランブルの白線（OSM の 15 本＋写真）、排水溝、舗装の模様、点字ブロック。
- **基準面の統一**
  - `TERRAIN_ALIGNMENT.md` の D1〜D4 を行う（0.54 m の差もここで解消する）。
- **駅側**
  - 高架の歩行者デッキ（8 位）、しぶにしデッキ（17 位）、駅舎の見える面（6 位）、ハチ公広場、売店（20 位）。
- **地下鉄の出入口**
  - 6 か所（18・19・21・23 位ほか）。同じ形が多いので、1 つの部品を使い回す。
- **街路設備**
  - 信号（OSM には 4 基しかないので、写真から台帳を補う）、街灯、標識、ガードレール、樹木（6 本）、高架の線路。
- **止める条件**
  - 写真と OSM で、位置が 1 m 以上食い違うとき。この場合は台帳に記録してオーナーに確認する。

## C3 — 昼夜と写真品質
- 5 視点の昼夜の画像と、写真の撮影位置を割り出したカメラごとの比較画像（同じカメラ・時刻・季節）。
- 各建物の色、ガラス、発光、影、輪郭を評価する。
  - 平均の RGB が合っても完了にはしない。形の比較と主観の評価を並べて書く。
- WebGL での見え方の差（MAGNET のガラス +34 など）を、ここでまとめて直す。
- 自由に歩き回って、破綻（裏側の欠け、浮き、二重の表示）を探す。

## C4 — Core v1 の凍結
- 5 視点×全周で、目立つ未完成の区画がないこと。残った課題は理由付きで台帳に載せる。
