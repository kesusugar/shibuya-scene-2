# 外側地形とJR南東側施設

Coreの元の地面の外側へ、国土地理院DEM5Aに基づく地形補填を追加。範囲は東西-250〜260 m、南北-300〜220 m、格子5 m。元の交差点のGLBはバイト一致。輸出後25,623三角形の平面投影と元の地面との重複は0㎡。継ぎ目20 mは元の面の最寄り点の補間高さへ接続する推定処理。道路・歩道の仕上げ、工事床、縁石を実測したとは扱わない。

## 制作と照会

- スクエア36点・フクラス135点は全点に高さを取得。元の屋根と壁を移動せず、下端の隙間だけに裙を追加。
- 駅西側高架の支柱8点はT.P.15.24〜16.04 mのCore/DEM補填へ接地。上面は保持。
- 銀座線上屋の地面照会は4点すべて有効。上部の推定ホーム床・M形フレーム・ドア・元の屋根は保持。地形を取得しただけで、内部の床が実測値になったとは扱わない。
- JR南東側のbldg_d7fb4726は、元の壁・屋根を保持して白い壁の縦長窓・桟・階の帯を制作。2024年1月の駅正面写真は種類の補助。施設IDとの対応・2025年10月の工事状態・窓割りと寸法は未確認。522点中498点に地面照会が有効、24点は未取得。C群の同じsource_idを除き、独立したB資産を通常表示へ追加。

元の屋根・上面の高さを保つことと、写真品質・施設同定が完了したことは区別する。駅側の全6種がB資産を持つが、全体が写真品質で完成したとは扱わない。
