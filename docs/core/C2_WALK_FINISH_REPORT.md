# 点字アプローチの補足・施設前接続と区画裏面

元のCore地面・164枚の点字面を保持。残る14横断歩道の28端点を調べ、16端点へ108枚を補足。12端点は完全な警告面を置けず、別の位置を創作して道路へ置かない。さらに元の点字面と補足面からモデル上の地下鉄出入口6か所へ166枚の接続面を追加。上屋の形・位置と階段を再制作しない。

## 制作時の修正

補足の初版は台板の9点検査だけを使い、歩道の小さな隙間を突起が横切って生成エラーになった。突起と線の予定頂点も歩道へ照会してから警告面の位置を選ぶ方法に変更。道路と地形補填へ点字を置かない。

施設前の経路は歩道上で出入口・樹木・支柱・小施設を避けて探し、歩道に収まる直線へ整理。柵の線も障害物へ追加して柵の端を回る側を選び、既存区画と警告面の外形で新しい面と突起を切り詰め、重ねない。警告面中央の2 mm目地の真上を検査したところ隙間として検出されたため、6 mm以内の横方向・縦方向の目地も考慮して連続性を検査。広い隙間を許容する変更ではない。

像周辺の植栽2区間は初版で背面が開いていたため、寸法と段取りを保ち背面の石小口と笠石を追加。像、前面の配置、レールと低木は保持。

## 検証と未達

121テスト・型チェック・ビルド成功。実GLBの歩道接地（2〜7 mmの表示高さ）、6経路の連続性とモデル開口前の端点、2区間の背面の石壁、取得失敗の隔離、各資産の予算を確認。実GLBの投影では、追加面と元の面、接続面と先行面、全追加面と柵の4 cm幅の保護帯との重複はそれぞれ0㎡。元のCore地面・街路・164枚の点字資産はバイト一致。書き出し時の歩道端補正は0件。通常表示の東・西・北の出入口前、区画裏面、初期画面の夜を追加前後の同じカメラで撮影する。

実際の点字経路・階段方向・接続・10月状態は未確認で、正確なバリアフリー案内の完成とは扱わない。配置できなかった12端点、JR入口までの連続経路、像周辺全区画の外形・細部と銘文、残る広場設備は未達。今回の接続はモデル上の6か所であり、周辺すべての施設への誘導ではない。
