## dotsへ渡す共通仕様

- リポジトリ https://github.com/kesusugar/shibuya-scene-2 の最新mainから開始し、依頼ID・対象パス・基準commitを明記。上表だけを渡して全建物を再生成させない。
- Blender 4.2.3、GLBはメートル、スケール1。小物は地面中心を原点、幅/奥行/高さ・正面方向を明記。既存建物は現在の地理座標とT.P.15 m基準を保持。
- 小物はモデルと配置を分離。建物への装飾は親資産と取り付け面を指定し、変更しない部位のハッシュ/幾何比較を保存。
- GLB、編集可能なblend、再生成スクリプト、寸法表、写真URL・著者・ライセンス・撮影年月、比較画像、残る推定を納品。元の資産別予算を引き上げない。
- 位置が分かる広角写真＋形が分かる近接写真が理想。測れない寸法は標準寸法/相対推定と記録。Street Viewをテクスチャに使わない。
- dotsは造形/局所修正、Codex側は地面追従・配置台帳・重複除去・衝突・通常表示・昼夜撮影・負荷確認を担当。画像の巧さだけで接地や性能を合格扱いしない。
- ユーザー指定の建物丸ごとの置換禁止を継続。参考画像が南麻布等の別地域なら「形状見本」とし、渋谷への設置根拠を別に用意する。

この一覧は制作計画であり、今回のPRで90候補を実装したわけではない。新しい参考資料が得られたら条件付き候補を確定し、十分な既存部位は候補から外す。
