# ハチ公像と台座の部分試作
PR #27マージ後、ハチ公像と石の台座を独立street/hachiko資産として通常表示へ追加。点字・蓋の次の広場設備として、汎用犬の流用ではなく写真の座った姿勢・左右の耳の違い・前後脚・尾・首輪をBlenderで制作した。

## 根拠と未確認事項
- 位置: OSM node/597685675、2025-06-08の版48。履歴から2025-10-31以前の最終版を採用。東11.568 m、北-48.686 m。座標の測量精度は独立検証していない。
- 形: RuinDig/Yuki Uchida、2025-07-13の094/095、CC BY 4.0。正面で耳・脚・銘板・台座を確認。
- 補助: Joli Rumi、2025-11-01、CC BY-SA 4.0。側面と尾・金属の基台を確認。11月を10月の確認済み写真として扱わない。
- 7月の一時的な選挙告知板は10月の模型へ採用しない。広告内容は後工程。

台座と像の寸法、向き、10月時点の状態は推定。写真カメラの校正は行っていない。写真と模型の比較は輪郭・種類の確認であり、画素位置・IoUの独立精度の保証ではない。背景の建物同定・撮影方位も未確定なので、向きを写真から確定したとは扱わない。

## 制作と見直し
ブロンズ像を連続メッシュで制作し、目・鼻・口・首輪・足先を補足。石の台座、暗い足元、金属の基台、縦の銘板を追加。風化と石材は自作ノイズ、銘板はNoto Serif CJKによる自作組版。写真テクスチャはなし。実際の字形・毛彫り・風化・顔の微妙な形は未達。

初版は首と頭がつながった単調な輪郭だった。v2-neckでは首の形だけを変更し、頭との境を出した。台座は写真より幅広く見えたため、v3-plinthで台座の平面寸法だけを絞った。像の姿勢・色と地面はこの反復では変更しない。前後の画像と反復記録を保存。

正面が影の中で黒くなり顔の細部が読み取りにくかったため、最後にブロンズのmetallicを0.7→0.35だけ変更。酸化表面の近似で、実物の金属度を測ったものではない。光・露出・他の資産・色・形はこの反復で変えない。

足元9点を既存歩道へ照会し、最低点T.P.15.439 mへ接地。最大約2.6 cmの埋まりで浮きを避ける。歩行地面は従来通り。失敗時は補足資産を隔離し、他の表示を続ける。

## 検証
102テスト、型チェック、ビルド成功。実GLBの台座底面と歩道の照会、点字ブロックとの離隔、像・台座・銘板の存在、材質の発光なし、正常読み込みと空・取得失敗時の隔離を検査。

同じシーンのカメラによる前後比較と、正面・側面の写真との形の比較を保存。初期画面昼夜・広場からの視点を含む最終5視点、追加前2視点で読み込みエラー0件。実写真との顔・表面の忠実度や実測寸法、実地の照明、オーナーPCのFPSは未達。

## 次
