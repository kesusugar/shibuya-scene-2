# 5 視点で見える欠落と優先順位 Top 20（Gate C0）

## 測り方
- **視点**：5 つ（`CAMERA_REGISTER.csv`）。目の高さは 1.6 m。
  - 位置は OSM と既存アセットから決めた。現地写真で確かめたものではない（`UNCERTAINTIES.md` U1）。
- **建物の形**：旧データ `public/data/shibuya-scene-data.json` の 666 棟を、外形から上に伸ばした柱として扱った。
  - 高さの出典
    - PLATEAU の最高点：592 棟
    - 既定の 9 m：52 棟
    - 階数×3.4 m：16 棟
    - OSM の height：6 棟
  - 屋根の形、ひさし、看板は入っていない。
- **見え方の計算**：Blender Cycles で、建物ごとに色を変えた物体 ID の全周パノラマ（1440×720）を描いた。
  - 各建物が全周（球面）のどれだけを占めるかを、立体角で重みを付けて数えた。
  - 方位は 60 度ごとに分けて `VIEW_COVERAGE.csv` に記録した。
  - これは形だけの計算で、昼夜の違いや看板の発光は含まない。
- **優先度の点数**：`0.45×画面に占める面積 + 0.25×見える視点の数 + 0.20×目立ちやすさ + 0.10×未完成の度合い`。
  - 画面に占める面積は、その建物がいちばん大きく写る視点の値を、全建物の最大値で割ったもの。
  - 目立ちやすさは、旧プロジェクトでの扱いから決めた仮の値（`tools/core/build_register.py` の `salience`）で、実測ではない。
  - 重みはパック 01 の暫定値で、オーナーが変えられる。
- **パノラマ画像**（`coverage/<視点>_status.png`）
  - 上下の範囲：仰角 −45〜+45 度
  - 色：緑＝完成、黄＝レビュー中、橙＝制作中、赤＝未着手、灰＝地面、水色＝空
  - 中央が北（0°）で、右へ進むほど東になる。

## 数値だけでは決めないこと
- 3 位の雑居ビルと 7 位の渋谷駅前ビルは、写真では大型の看板やビジョンで非常に目立つ。
  - 計算では看板を形に入れていないため、実際の寄与は点数より大きいと考える。
- 地下鉄の出入口と売店は、全体に占める割合は小さい。
  - ただし歩く人の目の前にあり、欠けると「舞台セット感」が強く出る。
- スカイラインの 5 棟（4・5・9・10・11 位）は、順位は高いが距離が 125〜285 m ある。
  - 細部より、輪郭・高さ・ガラスの色が合っているかが重要になる。
