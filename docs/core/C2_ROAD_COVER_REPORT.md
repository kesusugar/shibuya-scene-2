# 円形路面蓋の部分実装
PR #26マージ後、排水設備候補からM027で確認できる円形路面蓋1個を通常表示へ追加。用途は未確認なので排水用・下水用と断定しない。交差点全体の側溝整備ではない。

## 制作と比較
写真は2025-09-01、Taufik、CC0。既存の建物カメラ（RMS 11.4px）から、中心と左右の金属縁を地面へ投影して位置・径を推定。最終径は約0.38 m、中心は東-6.294 m・北-2.369 m、地面T.P.15.216 m。これは道路の位置精度の独立検証ではない。原画素と投影座標はlayout.json、出典はSOURCES.json。

Blender 4.2.3 CLIで固い蓋・枠・模様・明るい補修跡を生成。写真テクスチャなし。初版の補修跡は均一な円だったため、外周だけを不均一に変更。拡大比較で縁の読み違いも見つかったため、金属の縁へ投影入力を修正。模様・補修幅・色・独立測量位置・2025年10月の状態は未達。周囲の白線と人物は実写真と大きく異なり、蓋の追加でそこまで改善したとは扱わない。

地面の12mm白線と重ならない16mm（模様17mm）のオフセットは描画都合で、実物の段差ではない。道路・建物・既存設備は元のGLBを保持。歩行判定は元の地面。失敗した補足資産は空のrootとエラー表示で隔離。

同じ入力写真への再投影では、描画中心は原画素の右0.18 px・上3.78 px（主に表示オフセットの影響）。読んだ金属縁の横幅88 pxに対し、枠を含むモデル外形は95.54 px（約8.6%大きい）。枠の定義・遮蔽・手読みも差に含まれるため、独立した位置精度や合格率とは扱わない。数値は `projection-check.json`、比較画像では補修跡がまだ均質で、摩耗・汚れの差も残る。

## 検証と証拠
- 追加資産962三角形・3描画単位・57,012 bytes、全体338,757三角形・261描画単位・21,658,484 bytesで既存予算内。既存20GLBのバイト一致を記録。
- 99テスト、型チェック、ビルド成功。実GLBの道路への接地オフセットを照会、材質の発光・写真テクスチャなしを検査、小寸法の正常読み込みと空・非有限・取得失敗を検査。
- `before/`は同じビルドの`drainage=off`、`after/`は通常表示。v1は最初の均一な外周。初期画面昼夜、近接、M027の状態とエラーはcapture_log.jsonへ。
- `boards/photo-before-after.png`はM027と同じ視点で前後を拡大。`boards/close-before-after.png`は近接。
- FPSはオーナーPC未測定。独立測量や別写真との位置照合は未達。
