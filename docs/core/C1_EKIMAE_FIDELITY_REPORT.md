# 渋谷駅前ビル：写真に基づく外装と看板の再構成

## 変更点

旧版はカフェと屋上画面を長い東面へ反復し、隣接する HiT 画面を短い北面へ配置していた。同じ北東視点で見ると、2025 年 1・2・11 月の写真と左右関係が逆だった。今回、元の PLATEAU の壁・屋根を維持しながら、駅前ビルのカフェ・飲食店帯・Samsung 画面を北東の曲面と短い北面へ、赤い窓割り・eyeCity・HiT を長い東面へ振り分け直した。別の写真に見せかけるためのカメラ反転ではない。

- 2–3 階相当の広いカフェ窓、金色の横帯と側柱、入口の枠・把手、装飾植栽を再構成。
- 中層の細い窓枠・横桟、暗い室内の輪郭と天井帯、外壁タイルの見切りを追加。ガラスは部分透過。内部の家具配置・奥行は推定。
- 上層の飲食店帯は同じ 2025-11-01 写真の切り出しを一度だけ使用。旧版の低解像度由来の画像を原寸 4032×2268 から再切り出し。
- 同じ写真に写る縦長の 17LIVE 看板を追加。2025-10-30〜11-30 の掲出期間は告知で補助確認。
- 屋上画面の支持鉄骨、斜材、上部の灯具を追加。Samsung と隣接 HiT は別の画面で、連結した一枚の広告にしない。
- HiT 写真の左端は撮影範囲外。見える部分を既知の 16 m 幅相当へ仮割り付けし、残りは無地の暗い板のまま。未知の広告を生成・延長していない。この 16 m は写真対応の推定で、測量値ではない。

## 保全

- `source_id=way/60739635`、元の PLATEAU 壁・屋根頂点をそのまま維持（既存の角置換部分を含む `ek_wall` / `ek_roof` の頂点配列が前版と一致）。
- 既存の 82 点の地面照会記録を明示して再使用。T.P.15.29 m、PLATEAU 基準との差 0.05 m を維持。今回新たな地面測量をしたとは扱わない。
- QFRONT、西武渋谷、他の建物、道路、シーンの樹木を変更していない。追加した葉は店舗外装に属する小さな装飾。
- メートル単位。既存の地理座標を保つ建物資産のため、原点を新たに中心へ動かしていない。

## 再生成・編集

`assets/buildings/ekimae/README.md` のコマンドを参照。Blender 4.2.3 で本体と 2025-11 看板 GLB、編集用 `source/blender/ekimae-fidelity.blend` を生成する。blend 内のテクスチャはパック済み。以前の `ekimae-uv.blend` は前版の履歴で、今回の編集対象は fidelity 版。

通常は既存の地面 GLB に対して照会する。限定環境での再生成には `--recorded-ground` を明示して既存 82 点を再使用する。これは新しい照会と同じものだと偽装しない。テクスチャの再切り出しは Python + Pillow + NumPy と EK01 の元画像が必要だが、モデル再生成には同梱の切り出し画像だけで足りる。

## 確認結果と残る差

- Blender 4.2.3 実行、GLB 書き出し・再読込・正面と側面描画を実施。
- 合計 23,822 三角形、27 プリミティブ、2,048,704 bytes。B 予算 120,000 / 40 / 3,000,000 bytes 内。予算を変更していない。
- 位置の有限性、既存 X 境界、元の外殻頂点、原点と地面記録、8 種の看板と色・発光テクスチャ、Samsung / Gusto の前面へのレイ判定を確認。
- Vitest の看板数を名前付きの 8 種へ更新し、旧版の誤った東面を狙うレイを実際の北東曲面へ変更。実メッシュから画面高さと展開長を測るテストを追加。既存の source_id 除外・有限性・境界・高さの検査は削除していない。
- 全体の `npm test` / typecheck / build / ブラウザ統合は未実行。限定的な作業スナップショットに全依存関係と配信用資産がないため。個別 GLB の合格を全体試験の合格とは扱わない。
- 比較画像の前後は同じカメラ・照明。写真とモデルは近い側の視点だが、完全な写真カメラ校正ではない。元写真の広角・傾き・遮蔽物は一致させていない。
- 背面・区画境界、窓の正確な間隔、内装、装飾の葉、文字の細部、HiT の欠落部分、写真の曲面の透視が焼き込まれた店舗広告は未達。『実写同等の完成』とは判定しない。
