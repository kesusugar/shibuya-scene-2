## 配置と座標系

### 設備

- 低木はGLBノードに含まれるworld配置をそのまま使用。6株の根元は `models/shrub_roots.json` と同じ。1024px自作RGBA、MASK cutoff 0.5、doubleSidedを保持。
- 座面だけの親をThree.js `(11.568175521259887, 0, 48.68573220011713)`、Y回転35°、scale=1とする。左右子rootのYは0.4710693359375／0.4155540466308594m。T.P.15mを加算しない。
- 地面GLBのSHAは提供資料の基準と同じ `37755dd24d3fe78418b3133210a6dc05ebe2c3c2f615b5a8bd22a4db6279dd32`。左右9点ずつの基準を継承し、変換後の座標・高さを回帰検査。最大埋まりは左右約39.7mm、平面範囲は左右各2.35mを維持。
- 旧記念碑は既に別資産へ置換されており、今回削除した旧panelは低位置照明の役割。独立した石碑GLBは変更していない。

### 像rootの向きと接地

`transform.json` の正面ベクトルと正規化行列を照合し、正規化後が−Zになることを確認。配信GLBとcanonicalの位置・法線・UV・indexは既存テストで完全一致し、ノードはidentity。正面軸をファイル名から推測していない。

駅側地上カメラは `pose=20.5,-46,2.05,11.568,-48.686,1.5,52`。南側の連絡通路・駅コンコースが画面左、駅前ビルの赤灰色ファサードが右になる背景関係を先に固定し、July094/095の銘板面と台座の四辺を見比べた。旧35°では駅側から側面を見る関係だった。候補−65°を実描画し、駅側で銘板面と台座正面を確認して採用。写真との完全なカメラ一致・精密測量を主張しない。精密角度は未確定で、採用値は推定。

- 希望正面 E=0.906307787、N=0.422618262。`atan2(-E,N)=-65°`。
- world正面 `(0.906307787, 0, -0.422618262)`。東・北を基準にした方位角は65°。
- 平面アンカー・一様縮尺・スキャン形状・UV・法線・像台座一体構造は不変。
- root Y：0.3795121888979883 → 0.3852884863052187m（+0.0057762974072304m）。
- 下端371点／371境界辺を新しい姿勢で地面へ再照会。最大gap −1mm、最大埋まり72.293mm（旧86.243mm）。凹凸を消すためのメッシュ加工や地面変更はしない。
- `scan-placement.json` のmatrix／inverseMatrix／groundを同期。設備用layoutの35°は変更せず、座面・低木・大木は追従させない。

## 読み込みと予算

独立GLBをPromise.allで取得し、全取得後にlayout順で取付。1件失敗時はrootを公開せず、parts/mesh/triangleを0にして失敗を報告する。readyの早出しはしていない。

`street=off`、`boxcontents=off`、BOX建築が未ロードなら内容物のJSON・GLB取得を開始しない。BOX建築本体は既存建物診断仕様のまま。無効状態は`off`、読込失敗は`ok:false`。

`evidence/hachiko-final-fit-20261017/before/` と `after/` は同じ10視点・画角・解像度・昼夜・quality。`comparison-check.json` で実camera記録も一致。beforeはPR88のbundle、afterは本実装のbundleであり、旧素材レンダーではない。各PNGを開いて形状・接合・遮蔽を確認した。

- `statue_station`：背景2地物、銘板と正面。`statue_station_oblique`：台座側面と近傍設備。
- `statue_top`：像だけの回転と設備35°の維持、両側6株。`shrubs_close`：旧コア／針の除去、石縁とレール、保持した石。
- `contents_front/oblique/night`：ガラスを通常状態に戻したまま、机・モニター・PC・入口文字・青札。画面は元素材どおり暗い無地で、架空の広告や過剰発光を追加しない。
- `box_accessories`：通常外側近景で小型ドームと2灯、屋根角との位置関係。`box_oblique` と `fit_overview`：既存施設との関係、通路・全景。
- `regression/`：street OFF等の画面／取得ログ、短距離カメラ移動による低木の3フレーム。ここにある屋根角の拡大は初回調整時の記録。最終の器具拡大・夜景は `final-details/`。`iteration1/` は幕板に隠れていた初回配置の比較記録。補足拡大を通常景観の見え方と混同しない。

細葉は距離により細部が読めなくなる。精密な樹種・現況との完全一致は未確認。大きな重複・逆向き・二重座標変換・入口閉塞を認めず、採用GLBの成功状態とHTTP/JSエラーを画像と照合した。カメラ再利用処理はPR88の修正を維持。

## 検証結果

最終実行結果・対象コミットは本書末尾の追記およびPR本文を参照。先行実行では撮影との競合で地面2検査が時間超過、通常の単独実行で解消した。旧ノード名を参照する2検査は、新座面への交差検査／保存済み旧GLBへの歴史比較へ更新した。失敗を無視して成功とは扱わない。
