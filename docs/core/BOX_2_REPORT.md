## 年代・材質・出典

丸i・犬・名称配置・FUN・スポンサーは2024年公開写真に基づく。2025年10月の確定状態や2026年の継続掲出ではない。時計形状は2024年設置写真、文字盤は2026-08-08の08:08:08の静止スナップショット。時刻連動・アニメーションは追加しない。この年代混在を通常画面の注記とレイヤー名にも記録。

元の名称は建築枠の非発光材だったため、写真の発光名称を表すために丸i・犬と同系の弱い淡色発光を配信側に設定した。昼夜の実測光量・色温度ではない。ほかの部品の材質・時計の作者作成文字盤画像は保持した。時計の画像は写真や切抜きではない。

各パッケージのREADME・PROVENANCE・推定・元manifest・必要なフォント通知を `source/exterior-signs/` に保持。公開用に選択した入力スナップショットであり、完全ZIP全ファイルを収録したとの主張はしない。商標・図柄・写真の権利は各所有者のまま。元写真・PDF・切抜き・ダウンロードした公式ロゴは再配布しない。

## 検証と予算

- 時計の未使用UVを、テクスチャのない4プリミティブからだけ削除。形状・法線・インデックス・文字盤のUV・画像ピクセルは元候補と同じ。時計は1,507,140 bytesになり、画像縮小・描き直し・ポリゴン削減は不要だった。
- BOX全体は**2,734,704 bytes / 54,793三角形 / 30プリミティブ**。B予算3MB / 120,000 / 40を緩和しない。既存の全体予算検査も使用する。
- 小さい丸i／犬が建物用の1m最小外形判定で拒否された問題を修正。建物本体の1m条件は維持し、看板レイヤーだけ1cm超を許容する。空形状・NaN・材質欠落・巨大サイズの拒否は維持。実物を無意味なダミー形状で大きくすることはしていない。
- 新規4テストで、配信形状・法線・文字盤画像の保存、単一の正向き変換、全軸同率、取付余裕と左右順序、本体の固定ハッシュ、6レイヤーの登録を検査。共通loaderにも小型看板の採用／壊れた形状拒否の回帰を追加。
- 通常品質・通常の街の一覧で、同じカメラの全景・正面・斜め・屋根近景・時計近景を比較した。変更前の全景・正面・斜めはPR78の画像を再利用（同じ本体・カメラ・表示条件。PR78の面積ゼロ1面除去の画像同一性記録を根拠にする）。近景だけmainから新規撮影。

最終結果：**53ファイル・238テストすべて成功、型検査・Viteビルド成功**。6視点すべてで通常表示の6レイヤーが読み込まれ、ブラウザエラー・資産失敗・layerErrorsは0。6つ目のFUN近景は、同じ固定本体から新レイヤーだけをQAルートで省いた変更前と比較した。製品側に非表示モードを追加していない。

屋根近景はレンダーを止めずに1秒間隔の2回を撮り、PNGが同一だった（`stability.json`）。FPSは取得・計測していない。固定視点の時間的安定性と、別の斜め視点での向き・重複・文字の見え方を確認した結果で、あらゆる機器・距離でのちらつき保証ではない。

## 残る制約・範囲

4対象パッケージはすべて採用し、取付先が不明なまま屋根へ並べた部品はない。保留パッケージなし。ただし、実寸・字体・細かな輪郭・色・発光・取付奥行・支持方法は推定であり、現地の完全再現認定ではない。FUNの判読不能な小マーク、犬の微細な輪郭等は元候補が省略したまま。時計の静止時刻と装飾文字の境界辺等の上流制約も保持する。

時計はガラス越しの展示で、既存の窓枠・反射・斜め視点による遮蔽は残る。時計を見せるために屋根・柱・壁・窓枠を削除しない。PR78の床接合・端部・地面の制約は今回改善したとは主張しない。

**対象4素材の取り込み・配置・本範囲の検証は実施済みだが、時計文字盤の全面視認は未達。第2段階の見え方をすべて完成と認定しない。** 夜の実景・光量の照合も今回の撮影では実施していない。

QFRONT、西武渋谷、採用済みハチ公、歩行表示・FPS、地面・接地・スカート、plaza-kioskのモデルは変更しない。第3段階以降は別PR。
