# ハチ公周辺の敷石と像の顔
PR #29マージ後のmainを基準に、2025-07-13の写真の灰色敷石を自作アトラスで追加。10.4×7 mの局所区画を既存歩道へクリップし、30 cmの方形、4 mmの目地と微かな石材差を表現する。寸法・方向・外形は推定。元の道路・縁石・白線・歩行面を変更せず、描画上の1 mmのオフセットだけを使う。夜の共通歩道設定を受け、独自発光を追加しない。

像の写真との形の差を減らすため、頭部の高さと幅、鼻先の大きさ、目の位置、口と耳の輪郭を見直した。最初の丸い口吻はまだ丸く見えたので、先が細くなる断面の連続メッシュへ変更し、元の視点で撮り直した。体・台座・像の配置・光・色はこの修正で保持。実彫刻の毛彫り・細部・寸法・10月状態・写真カメラ精度は未達で、写真品質の完成とは扱わない。

108テスト・型チェック・ビルド成功。実GLBの敷石頂点を元の歩道へ照会して1 mmの描画オフセットを検証し、写真テクスチャではない自作材質と歩道分類、取得失敗の隔離を検査。追加前2視点・修正後の近接/正面/側面、初期画面夜を撮影。ハチ公のGLB以外の従来資産は保持。
