## 対象を変更した理由

ENTRYは比較用にcaptureでHUDを隠し、time=dayで既定の昼を明示しただけで、写真合わせや別poseへ切り替えていない。通常表示の初期位置は維持する。初期画面で変わる範囲は左端の一部に限られ、画面全体の完成度が大幅に改善したとは扱わない。基準撮影の1000×750は今回の制作比較用。設計にある1440×900・縦長・左右約30度の総合確認はP4へ残る。
