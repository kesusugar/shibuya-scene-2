# Core補填面と外側の道路・歩道

PLATEAU2025の交通4タイルから車道・交差部・歩道・島を制作し、西・中央・東の3資産で通常表示へ追加した。元Coreの測った車道・歩道・縁石・白線は保持。仮のground_fillだけは、追加道路とDEMの両方が正常にロードされたときに表示から外し、実データの道路とDEM補填へ置換する。元Core GLBはバイト一致を維持し、ロード失敗時は元fillを表示する。

## 制作中に直した差

- 初版は元Core fillまで保護マスクへ入れていたため、109前などの道路が追加されなかった。測った道路・歩道を保護し、仮fillを置換対象に変更。元fill範囲の7,835.14㎡を交通面へ置換。
- LOD3優先、残りのみLOD2とし、Polygon内周穴を保持。T.P.0の12,378入力頂点（重複含む）は欠測としてGSI DEM5A・Core継ぎ目補間で推定。地面を地下へ落とさない。
- 初版で出力境界に小さな平面重複が出たため、追加側の保護幅を2cmへ調整。元の地面は動かさない。
- 白線の端でレイが数mm外れてz=0へ落ちる問題を修正。書出し道路三角形の最も近い点へ2cm以内で補間、範囲外なら白線を非配置。最終出力の非配置0。白線はCore資料の8帯の追加範囲で、外側の全交差点を網羅しない。
- 歩道を補うと、以前の追加点字で置けなかった12端すべてに警告面が収まった。独立street/tactile-outerに80枚。元164枚・追加108枚・施設接続166枚は保持。読み込み後の表示登録漏れも修正し、撮影で実際のscene登録を確認する。
- 新しい道路・DEMへ建物13資産の裾、駅西側高架8支柱・銀座線の接触点を照会し直した。屋根や上面を動かさない。建物の接地照会が範囲外の点はstats.jsonに保持。

## 検証

138テスト（既存と追加136件＋白線の実GLB接地2件）・型チェック・ビルド成功。全資産・全体の既存予算内。西49,609/中央37,737/東52,401三角形、各2.45/1.82/2.54MB。DEM36,728三角形・3.02MB。追加点字30,240三角形・2.05MB。

実GLBの追加交通面と保護Core、DEMと仕上げ面、新旧点字の平面重複はいずれも0㎡。Core・既存street・元/追加/接続点字・QFRONTのバイト一致を確認。結果はevidence/c2-exterior/geometry-check.json。元の屋根の全頂点・重複・予算・ロード失敗時のfill継続/測った面の保持をテストする。

追加前5視点、後9視点を保存。同じカメラの前後、初期画面・左右・広場・ハチ公周辺の昼夜を撮影し、根拠のある形の追加・資産成功・scene登録・エラーを確認。写真とのカメラは未校正。q=low/SwiftShaderで撮影し、実機FPSの合格とは扱わない。

## 残る差

縁石15cm/横断歩道端2cm・1m平坦/1.5m傾斜、白線45cm・間隔45cmは標準値による推定。仕上げ高・段差のない全歩行経路・点字の実位置と経路・排水や摩耗・店舗前の全敷石区画・2025年10月の状態は未達。109などの広告、外装の実際の寸法、遠景Cの個別精密化、駅屋根や屋上のPLATEAU不足も残る。

資料上の未着手を繰り返さないためASSET_REGISTER_V2.csvの19行を実装実態へ更新。写真精度の完成へ格上げしない。QFRONT・既存の高度な信号/樹木/入口と旧リポジトリ・西武作業を保全。
