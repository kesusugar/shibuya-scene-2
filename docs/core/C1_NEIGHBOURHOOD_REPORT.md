# 周辺4棟の個別外装

センター244、台帳名「渋谷平和クワトロ」、スクランブルスクエア、フクラスを通常building一覧へ追加。同じsource_idをCから除き、残る301件のC群を再生成。元の壁と屋根を保持し、独立したガラス、縦桟、腰壁、空の看板筐体を制作。写真を貼る方法や広告の複製は使わない。すべてB予算内。

## 写真を見て変えた項目

- スクエア：2023年の外観を補助に、細い縦桟・青いガラス・段ごとに切り替わる黒い縦帯を追加。初版で各窓の中央にも横桟を加えたが、縦方向の格子を弱め、容量も3.53 MBとなった。元の階境の帯を残して窓中央の横桟を除き、2.35 MBへ。屋根を動かす削減はしない。
- フクラス：2020年の写真に見える灰色の矩形腰壁を追加。初版は細い横線に見えたため、矩形の高さだけ拡大。写真の広告と工事状態を2025年へ移さない。
- センター街2棟：2023年の高所写真は構造の補助で、各棟との写真対応は未確定。個別のPLATEAU壁に窓・桟・空の店舗帯を追加する推定外装。施設の名称やライブ会場の外観を断定しない。

## 検証

112テスト・型チェック・ビルド成功。4棟の元の屋根全頂点を実GLBの共通座標で照合（2 mm以内）、重複除去1回、広告テクスチャ不使用、各予算を検査。4つの同一カメラで追加前後を撮り、初期画面の夜も資産成功状態とブラウザエラーを確認。写真とのカメラは未校正で、画素誤差の合格とはしない。

歩道照会はセンター244が60点有効・3点範囲外、クワトロが53点有効・1点範囲外。スクエアとフクラスは全点範囲外（36/135点）。屋根の基準T.P.15 mと元の高さを保ち、未測定の地面に全体を移動しない。次の地面拡張で足元を扱う。

## 残る差と依存関係

スクエアの屋上テラス・開口、フクラス低層の大きな張り出し・開放バルコニー、センター街各棟の実際の窓割り・色・看板内容、2025年の外観と夜の点灯は未達。低層形状は元のPLATEAUが表す分までで、新しい実測形状として認定しない。
