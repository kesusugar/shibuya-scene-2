# 周辺建物10資産の外装追加

109、マークシティ東西、高木、ビックカメラ、シネタワー、東側雑居、ヒカリエ、パルコ、ストリーム、サクラステージを通常building一覧へ追加。公式PLATEAU2025の壁・屋根を保持し、個別の外装を自作。広告写真は貼らない。対応した6件のC親を除き、残るC群は293件。

マークシティ東西は同じPLATEAU複合建物に対応するので1資産にまとめた（OSM2件の別名を記録）。段差のある複合建物は全体重心だけでは表裏を誤るため、元の閉じた殻の両側へ光線判定し、窓が内側へ入る向きを修正。元の屋根頂点を移動しない。

## 写真から選んだ形と修正

109は円筒の白い外装と細い縦目地、ガラスは低層だけ。数字は2019年の形を参考に自作近似。マークシティは2025年6月写真の白い横帯と横長のガラス。シネは2010年の構造補助から湾曲面のガラス帯、古いSEGA広告は非採用。ヒカリエは2025年3月写真から低層の小さな金属開口と上層ガラス。パルコは2024年の写真から傾いた白い低層壁と上層ガラス。ストリームは誤って候補になった屋内エスカレーター写真を除き、2023年12月の外観から白い縦帯を追加。サクラは2023年の補助から青いガラスと白い角の斜材。初版の過密格子で予算を超えたので、窓中央の余分な横桟を除きピッチを広げた。高木・ビック・東側雑居は2025年高所写真の候補と台帳情報から個別外装・空の看板筐体を制作、写真同定は未完。

撮影時は109・ヒカリエの確認カメラが手前の建物に遮られたため、見渡せる視点へ補正。通常の初期画面は別に昼夜で確認。比較写真とビューアーのカメラは未校正で、画素誤差や年代一致の合格ではない。写真の作者・ライセンス・出典は各資産source/refs/SOURCES.md。

## 検証

132テスト・型チェック・ビルド成功。10資産の元屋根の全頂点を実GLBへ2mm以内で照合。C親の重複除去、マークシティの単一配置、広告テクスチャ不使用、資産/全体の予算を検査。10対象+初期昼夜、追加前6視点を撮影。エラー・資産失敗なし。q=lowでSwiftShaderを使用（FPS検証ではない）。参考写真・前後の比較板はevidence/c2-nearby/boards/。拡張DEMと元Coreの平面重複0㎡。Core地面・既存street・QFRONTはバイト一致。

DEM地形をX[-330,380]・Y[-450,350]へ拡張。これは標高補填であり、仕上げ道路は後続PRで制作する。窓割り・外装色・屋上筐体・看板・出入口・低層店舗・2025年10月状態・夜の点灯は実測未達。PLATEAUの屋上形状の不足も残る。旧OSM平面形は2026年9月取得であり、2025年の写真同定として扱わない。
