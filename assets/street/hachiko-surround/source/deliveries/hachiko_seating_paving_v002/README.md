# ハチ公周辺 石縁・銀レール・局所舗装 v002

## このパックの完成範囲

dot制作の独立素材パックです。Blender 4.2.3 LTSで再生成できるソース、編集可能なblend、左右別GLB、自作PBRテクスチャ、モデルのみのプレビュー、QA資料を含みます。シーン、リポジトリ、PRを変更していません。

1. **現行フットプリント互換部材**: `web/current_pair.glb`（推奨、左右独立root・共通画像）または `current_left.glb` / `current_right.glb`。既存の左右各2.35 m区間と前後二本レールの高さ・位置を継承。粒状御影石、細い縦割り、笠石の目地、銀管、支持と脚、非発光の横長照明を制作しました。実測モデルではありません。旧部材を選択的に除去してから使います。
2. **参照写真の弧状配置候補**: `web/candidate_curve_left.glb` / `candidate_curve_right.glb`。左右の部分的な曲線石縁とレールだけです。完全な一周、背面の植栽区画、樹木は作っていません。半径・端部・寸法は推定で、現況完成形と扱わないでください。
3. **大円舗装の割付候補**: `textures/paving_ring_candidate_*`。単一の大きな同心円、外周3列と手前の直線帯を自作。`web/candidate_paving_PREVIEW_ONLY.glb`は平面の確認用で、現地の傾斜や歩行地面を置換する資産ではありません。

## 保護・対象外

大木・大木の四面石囲い・他の樹木・ハチ公像のスキャン・低木・自然石・土・記念碑は含みません。QFRONT、西武渋谷、歩行表示、FPS、全域地形、道路、衝突判定も変更しません。

- ユーザーの640×480写真は撮影日不明。広い弧の石縁と大きな同心円・直線帯を確認できますが、工事後の完全な配置図にはできません。

- 背面・小金具・幅・寸法・4本支持ピッチ・地面接地は既存推定または素材制作上の推定です。日付不明写真を現況として復元したとは主張しません。
- 外部写真は同梱せず、テクスチャに写真の画素を使用していません。プレビューにも外部写真・既存樹木・像は合成していません。

## 再生成

1. Python 3 + NumPy + Pillowで `python source/make_textures.py`。
2. Blender 4.2.3 LTSで `blender -b --python-exit-code 1 -t 4 -P source/build_assets.py`。
3. 現行部材の斜めプレビューは同じコマンド末尾に `-- --render`。候補の技術配置シートは `python source/make_candidate_sheet.py`。レンダリング機が共有なら重いレンダーを直列実行してください。
4. `python source/validate_delivery.py` と `blender -b --python-exit-code 1 -P source/reimport_check.py`。

`hachiko_seating_paving_v002.blend`の既定表示は現行互換部材のみです。候補は別コレクションで非表示です。PBR画像はblendとGLBにパック済みです。

## 統合前に必ず読む

`docs/INTEGRATION_CONTRACT.md`、`docs/PROVENANCE.json`、`qa/`を確認してください。GLB単体の検査とモデルプレビューは、実シーンでの接地・重複・視線・歩行確認ではありません。
