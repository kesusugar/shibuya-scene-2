# TKTS カウンター・端末の局所接地案 v001

既存のTKTSカウンター v003と卓上端末 v001を、形状と素材を変えずに組み合わせた独立した確認用候補です。タブレットと閉じたノートPCを個別に平行移動し、既存の赤い上面との接地を調べます。実景への配置・設置高さの確定や、新しい机の制作ではありません。

## 最初に見るもの

- `evidence/01_before_after_local_assembly.png`：同じカメラと照明による前後比較。左は元の端末セットの相対位置を保ってタブレットだけ接地させた比較基準で、過去の設置状態ではありません。右が個別の平行移動による局所接地案です。
- `evidence/02_contact_support_detail.png`：評価済みメッシュの実際の水平面から求めた支持領域。緑が接地、オレンジが底面の張り出しです。
- `evidence/contact_report.json`：個別移動、接地面積、隙間、ケーブル端点、保存検証の数値。
- `tkts_counter_device_fit_v001.blend`：部品別に編集できる候補。照明・カメラ・参考写真は含みません。
- `models/tkts_counter_device_fit_v001.glb`：赤い上部シェルと支持が成立した既存端末のみを含む局所組立GLB。
- `source/assemble.py`：Blender 4.2.3用の再現可能な組立・接地確認スクリプト。

## 変更の限界

タブレットは前側と左側の赤い上面の接続付近に置き、後ろのスタンドと白い既存ケーブルが中央開口を妨げない位置を選んでいます。ノートPCは左リターンへ移し、その実際の底面が赤い上面に接する高さへ下げています。両者の同じ高さは既存モデルの上面を使った候補であって、写真から実測した関係ではありません。

ノートPCの元の幅304 mmに対して左リターンは推定280 mmです。左右それぞれ12 mmの外形張り出しを残し、底面の支持範囲を別途数値化しています。机を広げる、PCを縮小する、足や台を新設するといった帳尻合わせはしていません。

端末セットの旧PC底面約+72 mmは制作時の基準位置です。実在する高い棚を意味しません。写真上の上下差は奥行きとカメラの見下ろしでも生じます。

黒い既存ケーブルは、赤い縁に潜らず、かつ既存PC外形に端点が接することを確認した場合にのみ表示対象とします。接触しても端子・通電・実際の配線先を確定したことにはなりません。成立しない場合は元の形を編集用ファイルに残し、未解決の任意部品としてGLBから除外します。

## 保存と未確定事項

- カウンター6部品、端末13部品の元の形状・素材・モディファイアは変更しません。移動のみで、回転・拡縮はありません。
- 原本ファイルは変更しません。再現用原本を `inputs/` に同梱し、元のサインと縦モニターのGLBもバイト単位で保持します。文字形状は変更しません。
- カウンターの下端は証拠に基づく上部シェルの切断面であり、床ではありません。下部キャビネット・脚・隠れた支持構造は作りません。
- 世界座標、実景の正確なXY位置、2026年の現況、実寸、物理的な耐荷重は未確定です。資料の公開は2024年9月19日、写真撮影日は不明です。
- 配布物に写真・切り抜き・広告・画面UIを含みません。比較画像はモデルだけです。
- 実行環境、GitHub、QFRONT、西武渋谷、歩行表示、FPS、マージ、デプロイは変更しません。

## 再現

Blender 4.2.3 LTSと、比較シート作成用のPython/Pillowを使います。同梱の `inputs/` だけで組立できます。ネットワーク、元写真、元の制作フォルダは不要です。

```sh
blender -b -t 2 -P source/assemble.py -- --render
python source/compose_evidence.py
```

別の出力先を使う場合は `--out /path/to/output` を付け、比較作成にも同じ出力先を渡します。`--render` を省くと形状・接地・保存・GLB再読込の局所確認のみを行います。既存モデルの全面的な再検証は行いません。
