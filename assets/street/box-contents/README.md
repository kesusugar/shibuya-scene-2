必須3GLBは `assets/street/props/incoming` の指定ファイルのバイト同一コピー。TKTS統合版、縦モニター、赤いサイン、棚壁も検証済み配布GLBのバイト同一コピー。旧TKTSカウンター単体・端末単体・元の棚壁部品は追加ロードしない。商品・広告画像・画面UIは創作していない。
