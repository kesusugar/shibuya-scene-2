# Sources and uncertainty

CASIO exterior photograph in release dated 2024-11-15:
https://www.atpress.ne.jp/news/417308

The full exterior photograph was inspected privately, then the doorway header was enlarged for reading. The clearer frontal photograph confirms exact readable English case: `Tourist Information & Souvenir Store`. A circular information symbol is visible to its left. The trailing `& Souvenir Store` appears smaller and dark, while the main wording is red. The earlier oblique image alone was insufficient; the frontal image resolves it. No source photo, crop or photographic texture is included or redistributed.

Carrier proportions and location come from the existing project's SHIBU HACHI BOX generator: `Central_doorway_header`, dimensions [3.853,0.14,0.23], centre [0,-0.606,2.405] metres. The operator's 2024 plan provides building measurements, but it does NOT measure this sign:
https://shibuyaplusfun.com/news/detail/?cd=000153

This add-on records a 2024 observation; it does not certify an October 2026 sign survey or advertising state. Geometry is newly authored; red/white colours, Bfont typeface, spacing and symbol are approximations. Blender's bundled font is used internally and converted to meshes; no external font file is redistributed. Follow the repository's license for newly authored project materials.
