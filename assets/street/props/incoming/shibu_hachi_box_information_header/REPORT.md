# Validation and scope

Confirmed readable wording in the private full 2024 exterior reference, then checked the enlarged sign region: Tourist Information & Souvenir Store. The smaller dark trailing text was confirmed in the clearer frontal photograph and included. The circular i is a deliberately simple approximation.

Independent generation in a separate output directory with Blender 4.2.3 produces an identical GLB (SHA256 4e8ef5ea00f3d309eabda9d209ec3378e21410a98fc9ae5f48c35c7f61b18185). GLB structural validator passes: 1 mesh, 3 opaque materials, 832 triangles, 39,444 bytes, no images/textures/external resources. Bounds establish a bottom-centre origin and metric dimensions 3.650 × 0.004 × 0.180 m.

Editable blend validator passes: 4 component meshes, applied transforms, exact matching bounds, unit scale 1, no external libraries or FILE images. Generated GLB alone has no carrier or architecture. Context-only renders import the published parent architecture after saving the standalone asset. Parent publication files are unmodified.

The initial working preview used an outdated local parent and was rejected; final context views are rendered against shibu_hachi_box_revision/publication/asset/output/shibu_hachi_box.blend, not the obsolete final_output copy. The generator source accepts a context path explicitly, so no parent or absolute path is packaged into the GLB/blend.

No world placement, runtime registration, collision, walking, FPS, protected building changes, merge or deployment. Header dimensional assumptions, font mismatch, colour estimates and observed text are documented in README/SOURCES. A 2024 sign reference does not itself establish a current-date observation.
