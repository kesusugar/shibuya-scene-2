# ハチ公周辺の銀色二連レール：交換用局所モジュール

単体の制作・検証用。既存の街へはまだ組み込んでいない。現行の周辺GLB、像、石縁、樹木、歩行・FPS、QFRONT・西武は変更しない。

従来の生成元は各区間に丸棒の脚4本と丸い斜め桟4本を配置していた。2025年7月の近景で見える平板状の端部と薄い脚、二本の太い丸管の関係に合わせ、端部を連続した平板形状へ変更する。丸管の長さ2.25m、直径70mm、中心高さ0.65m/0.81m、前後間隔0.22mは既存モデルの推定値を継承。216三角形、1材質、画像テクスチャなし。

## 内容と再生成
- hachiko_dual_rail_module.glb / .blend：実寸メートル、底面・平面外接矩形中央が原点。Blender正面+Y、glTF正面-Z。
- source/regenerate.py：Blender 4.2.3。`blender -b --python-exit-code 1 -P source/regenerate.py -- OUTPUT`。外部素材なし。
- source/render.py / test_model.py：OUTPUTのGLBを読み戻して確認画像・形状検査。
- evidence：同一カメラ・照明での旧生成元形状と候補の比較、候補の正面・側面・斜め。写真の複製ではなく実GLBレンダー。

## 組込み注意
このモデルを既存銀色レールに重ねない。既存生成元の rail_<segment> / inclined_support_<segment> / leg_<segment> のみを置き換える。同材質で結合済みノードを不用意に削除しない。石材・照明・植栽・像に触れない。

placement.jsonは既存の配置推定を保持するための参考であり、配置操作は実施していない。石縁モジュールの中心から+Yへ0.12m、Z同一で揃う。石縁上端0.59mに対し、丸管下側中心0.65m。端板の張出しにより外幅2.262m、奥行0.290m、全高0.845m。

前後の画像は「旧生成スクリプトのレール部を抽出再現した形」との比較で、取得できていないmain全体GLBとのバイト一致や街全景の検証を主張しない。撮影は検査用の正投影、実写カメラの校正済み一致ではない。
