# Selective import guide

1. Import this GLB into a separate review collection. Do not overwrite a station shell or existing asset. The root `H_CV_002_JR_entry_fascia_early2025_UNPLACED` is identity from construction onward; its origin is the complete fascia envelope's bottom centre. Blender axes: X horizontal, Z up, front toward −Y. GLB is standard glTF Y-up; use the importer's axis conversion, not an added corrective root rotation.
2. Expected estimated envelope in Blender: X −2.4…+2.4, Y −0.101…+0.101, Z 0…1.12 metres. Scale, geographic pose and mounting height are unverified. `placement.json` intentionally has null world transform. No scene-specific offsets are supplied.
3. Before placement, compare the running scene and unmerged work with the target's exact identity. The four-generator check is bounded evidence, not a global absence claim. Preserve shared station/concourse/service/viaduct geometry. Do not remove generic fascia, louvers or historical components merely because their names look similar.
4. The dated red strip and three white text meshes are descendants of `DATED_2025_ENTRANCE_ONLY_SWITCH`. Hide this group recursively to disable that layer in a separate hypothetical review, or hide its four children; a plain empty object's visibility alone may not propagate in every engine. Doing so does not establish a different observed date-state. Keep the green/white identity graphics separate.
5. The blend contains a hidden `EDITABLE_text_sources_NOT_EXPORTED` collection with packed-font text. Edit the generator's explicit TEXT_LAYOUT calls for reproducible changes, or edit those font objects and deliberately rebuild mesh copies. Do not render both mesh and editable text copies together.
6. The review camera/lights belong to `REVIEW_STUDIO_NOT_EXPORTED`; they are absent from the GLB. There is no collision, navigation, passage, staircase, policebox, or automatic runtime registration.
7. Integration, publication or replacement is outside this package. No QFRONT, Seibu Shibuya, pedestrian display or FPS changes. No merge or deployment.
