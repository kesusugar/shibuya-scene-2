# 交番正面の局所加工用・PR82保存原本

`station-north-pr82.glb` はPR82マージ後の配信本体をバイト単位で保存したもの。
SHA-256は `ecd9095e10082dd166ef2291df775532d4b5019390b4094abaa1b7c551644649`。
この原本を通常表示へ重ねない。JR入口の看板・中央柱・浅い開口は保持する。

`opening.json` の西面北端矩形だけを、`stn_concrete` の元三角形0・507からクリップする。
手前にある仮囲い `stn_hoarding` の元三角形0・3にも同じ矩形を適用する。
それ以外の元三角形・属性・変換・屋根・庇・構造柱は保持する。
`build-report.json` は切除面積、両対象の元三角形、追加見込みと奥面、変換を記録する。

`node scripts/build-st-1.mjs` でST-1→ST-2の順に生成する。ST-1単独の旧出力でST-2を上書きしない。
配置の生成元は `../../../hachiko-policebox/source/st-2/placement.json`。
北端から3.1mという取付位置と寸法・0.70mの奥行きは推定。地面・通行機能・内部は制作しない。
