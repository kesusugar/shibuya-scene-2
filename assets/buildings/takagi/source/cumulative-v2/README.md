# 高木ビルディング 更新版

上層ファサード・折れ屋根のリブ・屋根面52の三角形分割修正と、2025年1月の写真を参考にした屋上IKEA看板をまとめた単体モデルです。

## 開く
- 完成モデル：asset/web/takagi.glb
- 編集用：asset/source/blender/takagi.blend（Blender 4.2.3）
- 比較：renders/oldest_before_final_after.jpg
- 実写とモデル：renders/photo_model_comparison.jpg（写真のカメラは未較正）
- 全体／正面／側面／看板正対：renders/after_*.png

4,919三角形、16プリミティブ、GLB 397,924バイト。外部画像・フォントは不要です。

## 再生成
ZIPを展開し、このREADMEがあるフォルダから、Blender 4.2.3の実行ファイルを使って実行してください。

    blender -b -t 6 --python regenerate.py

元モデル→ファサード・屋根修正→看板の順に再生成し、各段階のGLBのSHA256一致を確認します。GLB・編集用blend・生成統計JSONが上書きされます。元モデルの入力は別フォルダに保持します。Blender内蔵Pythonのみ使用します。任意の画像再生成：

    blender -b -t 6 --python render_views.py

完成blendとGLBの一致・外部依存の検査：

    blender -b --python verify_editable.py

## 範囲と注意点
- 元の座標系と接地形状を維持。再中心化はしていません。
- 看板の高さ・厚み・支柱位置と書体、窓割りは写真に合わせた推定です。実測図・公式ロゴではありません。
- 右側の支柱が長いのは、既存の低い屋根形状を保持したためです。背後の屋上躯体も保持しています。
- 隠れた店舗や対象外の外壁は従来の簡略表現のままです。建物全体の完全再現ではありません。
- 比較画像は同じカメラ・照明による単体モデルの検査です。ゲーム全景、歩行、衝突、FPSは未検証です。
- 2025年1月の歴史的外観を参考にしています。現在の店舗状態や2025年10月の看板を保証しません。
