# 駅前ビル・北側入口枠の限定修正

## 修正内容
北側の直線折返しにある入口の金色の左右枠・上枠と銀色の取手2本のみを、同じ方向・寸法のまま約2.47m移動しました。既存の終端黄色柱との食込みと、店舗・庇の端からのはみ出しを解消する「モデル内部の整合性修正」です。写真測量や実測の入口位置復元ではありません。

対象は84三角形・168頂点。元の生成コードの点・面構成を署名として照合し、共有材質の広い範囲を一括選択していません。座標の変更箇所以外のBINバイトは完全に保持しています。平行移動のため法線を変更していません。glTF仕様に合わせ、POSITION accessor 51の最小Xだけを実際の値に更新しました。その他のJSON値・UV・頂点索引・材質・ノードは不変です。

## 範囲と限界
- 元の正面入口、曲面、ガラスの割付、終端柱、庇、植栽、看板、配置アンカーは変更していません。
- 実際の出力頂点で、終端柱まで約0.05m、庇終端まで約0.70mの余裕を確認しています。これはモデル内の設計余裕であり、写真から測った寸法ではありません。
- 上枠と庇の取合いには元来の高さ重なりがあります。「全ての部材が非交差」という主張ではありません。
- 引継いだ細いガラス方立は、新しい枠中心から約0.30mずれた位置に残ります。左右対称な扉割付、開閉方式、扉枚数、有効開口は未確認です。歩行・衝突判定・FPS・全体シーン統合を検証したものではありません。
- QFRONT、西武渋谷および他建物、歩行コード、表示設定には触れていません。

## 再現
必要環境：Python 3の標準ライブラリ、Blender 4.2.3。ネットワーク・追加Pythonパッケージ・元リポジトリは不要です。

任意の作業ディレクトリから実行できます：

    python /path/to/package/source/run.py /path/to/blender-4.2.3 --render

この順序で元コードの関数から署名を再生成し、固定入力を照合、座標と必要な境界メタデータだけを修正、6項目のテスト、編集可能blendと4枚の比較レンダーを作成します。署名固定済みの場合、source/repair.py単体はPython標準ライブラリのみで同じGLBを再現できます。render_editable.pyは配信用GLBを再エクスポートしません。

最終GLB SHA256：4ecb3412bc946a8aa88ac9ab0ac4d9f415b8d5bcadac819ead9d8d59885b89c8。
