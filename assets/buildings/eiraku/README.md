# 栄楽ビル（MAGNET の東隣）

- アコム・レイク・アイフルの縦長の看板が付いた、細い 8 階建てのビルです（写真 M002、M014、M027）。
- PLATEAU 2025 では MAGNET の建物（`bldg_d47d8aa9…`）の一部として登録されています。屋根の高さは 37.34 m です。
- しかし実際は別の建物なので、ここに分けました。

## 作り方
- 形は `assets/buildings/magnet/source/blender/build_magnet.py` のコレクション `07_EIRAKU` で作っています。
- `web/eiraku.glb` は、そのコレクションだけを書き出したものです。
- 看板（アコム・レイク・アイフル）は、MAGNET の 2025 年の年代レイヤー（`magnet_signs_2025.glb`）に含めています。

## 精度
- 窓の配置は写真からの推定で、精度は低めです。
- 外形と高さは PLATEAU に基づいています。
