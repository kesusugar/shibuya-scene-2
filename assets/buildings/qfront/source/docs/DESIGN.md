# QFRONT Photorealism Challenge — Phase 1：資料収集と設計

- 作成日：2026-10-11（Phase 1）
- 独立プロジェクト `qfront-photoreal/`（Shibuya Scene には変更なし）

証拠レベルは次の4つで表記します。
- `[実測]`：PLATEAU や公表値
- `[写真]`：複数の写真で確認できるもの
- `[推定]`：写真からの推測。Phase 2 のカメラ解析で確定させる
- `[不明]`

## 1. 資料

**収集した写真**
- Wikimedia Commons の 127 件のメタデータを取得しました（カテゴリ QFRONT / Q-Front at night / SHIBUYA TSUTAYA）。

- ライセンス不明の 6 件は再利用しません。

**写真の使い道**

- 比較画像に写真を載せる場合は、作者とライセンスを明記します（BY-SA の写真を含む比較画像は BY-SA で公開）。

## 2. 建築の分析（写真の観察から）
1. **ダブルスキン** `[写真]`
   - 外側：白っぽいアルミの縦フィン（奥行きは推定 30〜40 cm）が約 1.0 m 間隔 `[推定]` で建物全周に並び、王冠の天端（52.1 m）まで連続しています。横桟は細く、階高の半分程度の間隔です `[推定 2.7 m]`。
   - 内側：ガラスのカーテンウォール。正面は曲面ガラスです（Q027）。
2. **平面**
   - 交差点側の正面は緩い円弧です（OSM、写真）。
   - 両側に平らな面が続き、角は面取りされています。
   - 東面（道玄坂側）には縦書きの TSUTAYA の大きな文字があります（Q118、Q096）。
3. **階構成**
   - 1F は高さ約 6 m `[推定]`：TSUTAYA 入口、Starbucks 入口、交差点側に張り出した庇（キャノピー）。
   - 2F〜3F：内側にX形の斜め柱（ブレース）が見える開放的な層です（Q128、Q107）。現在は 2F が Starbucks、3F が SHARE LOUNGE。
   - 4F〜8F：Q's EYE 帯。階高は約 5.4 m で、44.0 m に収まります `[推定]`。
4. **Q's EYE**
   - 正面の曲面のおよそ 14〜38 m に、黒いLED面があります `[推定]`。
   - 中央の矩形がメインビジョン（SMD）です。
   - 周囲のフィンの外側に砲弾型LEDが並んだ「アートビジョン」があり、文字やロゴがフィン越しに流れて見えます（Q031 の「QFRONT」、Q111 の字幕）。
   - 2023 年の写真では、王冠のフィン面にもLED表示があります（Q111 の Coca-Cola）。
5. **王冠（44.0〜52.1 m）**
   - 外周のフィンの内側に、黒い鋼製トラス（斜材を含む立体トラス）が透けて見えます（Q031、Q032）。
   - 天端の帯に QFRONT のチャンネル文字があり、夜は白く発光します。
   - 屋上デッキ（48.4 m）には設備機器があります。
6. **投光器** `[写真]`
   - 左右の正面の角、約 36〜40 m の高さに、腕木に並んだ多灯の投光器が付いています（Q032、Q111）。
   - 夜はこれが外壁を照らします（Q031）。
7. **年代差**（`refs/REFERENCE_REGISTER.csv` の era 列）
   - 1999–2004：初代スクリーン。
   - 2005–2012：2代目スクリーン。HMV や H&M の大型垂れ幕の時代。
   - 2013–2023：メイン＋アートビジョン。2F が Starbucks。
   - 2023-10〜2024-04：TSUTAYA 改装。
   - 2024–2025：現況（3F SHARE LOUNGE ほか）。
   - **再現する年代は 2024–2025 の現況を推奨します**（PLATEAU 2025 と一致）。構造は全年代で共通です。広告は架空または差し替え可能なデータにします。

## 4. Blender での制作設計
### 4.1 階層構造（`blender/blockout.py` が同じ構成で生成）

```
QFRONT_ROOT (m, Z-up, origin = 地盤 T.P.15.10 m の footprint 重心)
├─ 01_STRUCTURE    床スラブ・コア・柱（室内の奥行き用）
├─ 02_INNER_GLASS  内側のカーテンウォール（方立・無目・ガラス、曲面はガラスを分割して近似）
├─ 03_OUTER_FIN_SKIN 外側フィン（GeometryNodes で外形線に沿って配置）・横桟・ブラケット
├─ 04_QS_EYE       メイン SMD 面（発光テクスチャ）・アートビジョン砲弾 LED（フィン上にインスタンス）
├─ 05_CROWN        立体トラス・屋上デッキ・設備・QFRONT チャンネル文字
├─ 06_GROUND_FLOOR 1F 店舗（TSUTAYA / Starbucks）・庇・2-3F の X 形ブレース・サイン
├─ 07_FIXTURES     投光器アーム・東面 TSUTAYA 縦文字・監視カメラ・信号柱など
└─ 08_INTERIOR     各階の室内（照明・什器・天井）：ガラス越しに見える範囲だけ実体で作る
```

### 4.2 作り方
- **外形**：OSM の円弧と PLATEAU の5角形を合成した外形線を、スクリプトで生成します。高さは PLATEAU の3段の屋根に合わせます。
- **フィンと横桟**：外形線をカーブとして持ち、GeometryNodes の Resample で 1.0 m ごとに断面をインスタンス化します。断面には実寸の角Rを付けます（ハイライトを作るため）。
- **ガラス**：内側ガラスはパネル単位の厚みのある実体にします（裏面の反射と屈折を出すため）。Principled の透過 0.9、IOR 1.52、わずかな緑味を付けます。曲面の正面は 1.0 m 幅の平面パネルを並べて近似します（実物も分割パネルの可能性が高い）。
- **室内**：ガラス越しに見える 2〜8F に、天井グリッド、照明（夜は発光）、什器の簡易ジオメトリ、壁ポスターを置きます。奥行きは実体で作ります（パララックス用の板は使わない）。
- **Q's EYE**：
  - メイン：SMD の画素構造を法線とマスクで表現し、オリジナルの映像テクスチャで発光させます。
  - アート：フィン外面に LED 粒を並べ、Attribute で画像をサンプリングして発光させます。
- **王冠**：トラスを部材単位で配置します（上下弦材、束材、斜材、ボルトプレート）。黒いフッ素樹脂塗装を想定して粗さ 0.45 程度にします。
- **1F**：TSUTAYA と Starbucks の店構え（サッシ、自動ドア、内照式サイン、什器）。商標の文字はロゴ画像を使わず、フォントで近似します（権利のため）。
- **細部**：投光器（アーム＋灯体 6 台程度/角）、監視カメラ、雨樋、目地、シーリング。

### 4.3 マテリアル（PBR）
- **フィン**：アルミのフッ素樹脂焼付け（白銀）。金属度 0.6、粗さ 0.25〜0.35。縦方向の汚れ筋（雨だれ）をテクスチャで加え、上端は汚れを多めにします。
- **ガラス**：低反射 Low-E。わずかに青緑で、反射が強いです（Q118 で空とビルの映り込みを確認）。パネルごとに法線をわずかに傾け（±0.15°）、映り込みの歪みを出します。
- **トラス**：黒の塗装鋼。粗さ 0.45 で、ボルト周りに錆やチョーキングを少し入れます。
- **コンクリート、床、歩道**：手続き的なテクスチャ、またはライセンスを確認した CC0 素材（Poly Haven / ambientCG。いずれも CC0）。

### 4.4 ライティング
- **昼**：Nishita スカイ（太陽高度・方位は Q032 の撮影日時から計算）。周囲のビルは簡易な反射源として置き、ガラスの映り込みを作ります。
- **夜**：空は暗い青、街の発光と看板は周囲の箱に貼った発光面で表します。投光器はスポットライト（光源のIESに近い配光）、室内灯は面光源、LEDは発光マテリアルにします。
- **露出・色**：AgX トーンマッピング。実写と比べながら露出を合わせます。

### 4.5 検証用カメラ
- Q032（正面）、Q107（現況）、Q031（夕景）、Q027（曲面の拡大）の4枚で、PLATEAU の角と外形線をアンカーにしてカメラを解きます。手法は Shibuya Scene の Gate 1 と同じです。
- 合格判定は、同じ画角での3列比較（実写 / レンダー / 差分の注記）で行います。

## 5. 未確定・リスク
- フィン間隔、階高、スクリーン範囲はすべて推定です。Phase 2 の最初にカメラ解析で確定させます。
- 王冠トラスの部材配置は写真からの再構成になり、背面側は見えません。
- 店内は写真の範囲（Starbucks、TSUTAYA）でのみ再現します。商標の文字と映像はオリジナルの代替にします。
- CPU レンダリングの負荷が大きいです。4K の最終品質は 1枚あたり数時間かかると見込みます。プレビューは 960 px・64 サンプル・デノイズで回します。
