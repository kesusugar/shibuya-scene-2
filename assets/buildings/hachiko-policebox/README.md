# ハチ公前交番：2025年4月の可視外観（ST-2）

`policebox_visible_facade_2025_v001` を選択取り込みした浅い外観。交番全棟・裏面・内部・地下・入室機能ではない。
曲面の緑／銀の帯、銀色の外枠と庇、写真で確認された3か所の支柱・赤帯、浅い窓／入口の推定外装を採用する。
独立制作された形状を使用し、写真をテクスチャや公開比較板へ転用しない。出典と写真の権利境界は `source/st-2/SOURCE_REGISTER.md`。
明示的な素材ライセンスファイルはZIPにない。写真の再配布許諾や公式表示の正確な複製を主張しない。

警視庁の交番案内地点と2025-04-09写真の公共高架下通行部／駅西面との左右関係を照合し、
PLATEAU駅北側の西面北端区画へ推定配置する。BOX・plaza-kiosk・宮益坂側のJR入口とは別物。
共通地理原点とT.P.15m基準を用い、既存地面を照会。変換は配置行列1回、均等倍率1。
対応壁と手前の仮囲いだけを局所加工した駅GLBと組み合わせ、入口を元壁で塞がない。

原本GLBと生成元・出典・寸法・検証記録を `source/st-2/` に保持する。原本の推定下部背板1部品を省き、
代わりに駅の局所開口に左右・上の見込みと0.70m奥の閉鎖奥面を置く。新しい室内や床は追加しない。
原本の部品を材質ごとにまとめて描画単位を削減し、形状・均等倍率は保持する。
上部の窓代理だけをglass分類、緑の帯は材質未同定のwall、任意の簡略KOBAN表示はsignsレイヤー。
昼夜の創作点灯・時刻連動・警察設備は追加しない。

元blendとモデル単体レンダーはDrive ZIPに保持し、配信へ追加しない。
