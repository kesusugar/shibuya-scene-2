# 渋谷PARCO — 奥行きのあるテラス更新版

以前の浅い外装版とは異なる新しい単体パッケージです。旧ZIPは変更していません。旧版と重複表示せず、採用する版を明示して選んでください。

## 内容と使い方

- 実行用：parco_terrace_candidate.glb
- 編集用：parco_terrace_candidate.blend
- 再生成：scripts/rebuild.pyと同梱inputs/、registration/、verification/floor_coverage/coverage-proof.json。
- 正面/側面の旧配送レンダーは再生成用です。--renderで作成できます。現行mainとの比較は資産直下review/main-before-after.jpg。
- 再生成したcomparison-*.jpg、contact-*.jpgのbeforeは屋根22修正後の中間段階で、現行mainではありません。全メッシュを同じ不透明灰色で表示するclay図は、奥行きが材質や透明度による見せかけではないことを確認するためのものです。
- 寸法・階・誤差・未達の詳細：README.md、geometry/、registration/、verification/measurements.json。

今回は図面の画素や写真を使わず、数値化した形状入力だけで再生成できます。GLB/blendには参照写真・図面・外部テクスチャ・リンクライブラリを含めません。

## 再生成

Blender 4.2.3 LTS（0e22e4fcea03）、Python 3、NumPy、Pillowが必要です。作業用にフォルダ全体をコピーしてから実行してください。生成器はGLB・blend・検証レポート等を上書きします。

    python3 scripts/rebuild.py --blender /absolute/path/to/blender

各入力はファイル相対で解決し、別ZIP・外部リポジトリ・著作権保護された図面ファイルは不要です。--renderを付けると同じカメラのPNG/ボードも再生成します。原本固定用CANDIDATE_FREEZE.jsonは作業コピーに入れないでください。これを含む場所では原本保護のため生成器が停止します。

実行環境のパッケージ版と検査結果はreports/standalone-verification.jsonを参照。GLBは正確なSHA256一致を検査します。blendの保存時刻等によるバイト一致は保証しませんが、保存したシーンを再オープンし形状を確認します。

## 原点と階高

1単位＝1m。元の地理配置とフットプリントを保持し、底面中央原点へ再配置していません。Blender Z=T.P.−15m、GLBはY上向きで(X,Z,−Y)へ変換。建物全体の平行移動、回転、拡縮は行いません。

モデル4F/5F/6F/7FはZ=25.378/30.178/34.978/39.778m。相対階間4.8mと1Fから4Fまで15.1mは断面による根拠がありますが、絶対1F標高は未確定です。1F T.P.25.278±0.5mはモデル感度の仮定であり、現実の誤差上限や測量結果ではありません。最小地面T.P.23.4mを自動的に1Fと同一視していません。

## 範囲と不確実性

source171、upper108、152東端18.73mだけを対象に、床、庇裏、支持、側壁、奥の店舗面、北側の階が変わる歩行経路を作っています。一律8m押出しや暗いガラス帯ではありません。大きい角の昇降コアを保持。屋根22、実在のsource84/141ノッチ、屋根47、固定フットプリント、上部オフィス・対象外外装を保持しています。

公式4F模式図の相似配置はコーナーRMS0.538m、最大0.685m。昇降コアの独立照合RMS0.333m、最大0.460m、エスカレーター照合0.918/1.468m。これは図面登録の残差で測量精度ではありません。コア/角周辺約1m、局所約1.5m程度の不確実性を明示します。

東側主要奥行き約8.59–10.69m、南側戻り11.51m、広い喉部15.27m、コア側3.42–5.08m、北側2.27–6.45m。斜め横断レイの20–21mはテラス幅ではありません。部材厚さ・支持寸法・枠・階段・店舗反射は推定です。構造計算、法規適合、衝突判定/歩行可能性、測量済みの完成品ではありません。

北側5F未満の不透明仕上げは未確認、東側3F–4Fエスカレーター下部開口は保護屋根47を切る必要があるため未再現。一般的な内部の接合・交差が残り、一体化した構造/衝突シェルではありません。材質の光学特性、室内、実シーンの透明描画順・FPS等も未認定です。
